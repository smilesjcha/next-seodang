# Project Brief

## 프로젝트명

아름다운서당 AI 활용 스터디/발표 프로젝트

## 목적

- 토론과 발표의 질을 높인다.
- AI를 사고 확장과 피드백 도구로 활용한다.
- 좋은 프롬프트와 결과물을 축적 가능한 형태로 남긴다.

## 이번 세션 주제

- 여기에 주제를 적는다.

## 청중

- 여기에 청중 정보를 적는다.

## 원하는 산출물

- 발표 초안
- 토론 질문
- 피드백 메모
- 회의록 정리

## AI에게 기대하는 역할

- 사회자 보조
- 피드백 코치
- 반론 생성자
- 회의록 정리자

## 금지사항

- 사실 검증 없는 단정
- 원문 맥락을 무시한 요약
- 출처 없는 수치 생성
