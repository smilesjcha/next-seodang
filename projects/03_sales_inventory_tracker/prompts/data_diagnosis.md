# data_diagnosis(si)

## 목적
`01_load_and_clean.ipynb`과 `02_analyze_trends.ipynb` 결과를 보고, 예측을 진행하기 전에 **데이터 품질 문제**를 진단한다.

## 사용법

```
data_diagnosis(si) — 다음 데이터 진단해줘.

데이터 요약:
- 기간: <YYYY-MM-DD ~ YYYY-MM-DD>
- 상품 수: <N>
- 총 행 수: <N>
- 결측치: <컬럼별 결측 수>
- 이상치 (3-시그마 초과): <행 수>
- 추세 시각화 첨부: <차트 이미지>
```

## Claude가 할 일

1. 다음 4개 축으로 데이터 품질 진단:
   - **완전성** — 결측치, 누락된 일자
   - **일관성** — 동일 상품의 가격 급변, 단위 불일치
   - **이상치** — 시즌 외 폭증/폭락, 단순 입력 실수 의심 행
   - **충분성** — 계절성 탐지에 충분한 기간인가, 신제품처럼 짧은 시계열은 없는가
2. 각 문제에 신호등 (🟢/🟡/🔴) + 노트북에서 어느 셀로 가서 확인할지 안내.
3. 🔴 문제가 있으면 예측을 진행하지 말고 데이터 보완 권장. 🟡는 예측은 하되 결과 해석 시 주의 표시.

## 출력 형식
markdown. 4개 섹션 + 진행 가능 여부 결론 (✅ 진행 가능 / ⚠️ 주의하며 진행 / ❌ 보완 후 재시도).

## 가드레일
- 데이터를 추정·보완하지 않는다 (학생이 직접 결정).
- 차트만 보고 단정짓지 않고, 노트북 셀 어디를 다시 보라는 안내를 함께 준다.
- 회사 정보를 외부에 노출하지 말라는 한 줄 알림.
