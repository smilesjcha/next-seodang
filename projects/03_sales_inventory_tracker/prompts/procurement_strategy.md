# procurement_strategy(si)

## 목적
패턴 분석(노트북 04) + 매크로(05) + 가격 시그널(06) 결과를 종합해, **분기 또는 시즌 단위 매입 전략**을 만든다. 시점·수량·우선순위가 명시된 행동 가능한 계획.

## 사용법

```
procurement_strategy(si) — 다음 자료로 매입 전략 만들어줘.

대상 SKU:
<제품 식별자>

기간:
<향후 N개월 또는 다음 시즌>

입력 자료:
- pattern_summary_*.md (notebook 04)
- macro_context_*.md (notebook 05)
- signals_*.csv 의 최근 6개월 (notebook 06)
- (선택) forecast.csv (notebook 03)

회사 제약:
- 창고 가용량 (개): ___
- 매입 예산 한도 (원): ___
- 최소 발주 단위 (MOQ): ___
- 리드타임 (일): ___
- 결제 통화: KRW / USD / 기타
- 시즌 종료 또는 재고 소진 목표일: ___
```

## Claude가 할 일

1. 입력 자료를 다음 6개 차원으로 통합 분석:
   - **방향성** (추세 ↑/↓/정체)
   - **타이밍** (계절 저점 N월 + 매크로 충격 가능성)
   - **시그널 강도** (signals_*.csv의 최근 action 분포)
   - **변동성** (헷지 필요성 정도)
   - **제약** (예산·창고·리드타임)
   - **리스크** (예측 신뢰구간 + 모델 모름 영역)
2. 다음 형식의 전략표 작성:

| 시점 (월) | 액션 | 수량 | 단가 가정 | 예산 | 우선순위 | 트리거 조건 | 위험 |
|---|---|---|---|---|---|---|---|
| 2026-05 | 선매입 | 500 | 19,200원 | 9,600,000 | 상 | 6월 계절 고점 진입 전 | FX 추가 약세 시 단가 ↑ |
| 2026-08 | 모니터링 | 0 | - | 0 | 중 | z<-1 도달 시 추가 매입 | - |
| ... | ... | ... | ... | ... | ... | ... | ... |

3. **헷징 검토 권고** — 변동성이 일정 수준 이상이면 `derivatives_insight(si)`로 넘기라는 안내 한 줄.
4. 마지막에 **결정해야 할 질문 3개** — \"위 전략을 승인하기 전에 학생(=구매 담당자)이 본인이 답해야 할 질문\".

## 출력 형식
markdown. 의사결정 표 + 트리거 조건 + 검토 질문.

## 가드레일
- 자동 결정 금지. 모든 행에 \"학생 검토\" 칸을 두거나 트리거 조건을 명시.
- 입력에 없는 가격·환율·정책을 만들어 추론하지 않는다.
- 신뢰구간이 큰 항목은 \"잠정\"으로 표시.
- 회사 외부에 공유 금지 알림.
