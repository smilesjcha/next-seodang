# derivatives_insight(si)

## 목적
`07_derivatives_hedging.ipynb` 결과를 받아, **선물·옵션 헷지가 회사에 의미 있는지** 비즈니스 언어로 평가한다. 거래소 상장 패션 파생이 부재한 현실에서 OTC forward·FX 옵션·원자재 헷지 등 적용 가능한 도구를 매핑한다.

## 사용법

```
derivatives_insight(si) — 다음 분석으로 헷징 의미 평가해줘.

대상 SKU:
<식별자>

입력 자료:
- derivatives_*.md (notebook 07 출력)
- (선택) macro_context_*.md, pattern_summary_*.md

회사 상황:
- 연 매입 금액: ___ 원
- 매입 단가 표준편차 (지난 12개월): ___ %
- 결제 통화: KRW / USD / 혼합
- 공급사 분포: 단일 / 2-3사 / 다변화
- 재무팀 헷지 경험: 있음 / 없음
- 회계 기준: KIFRS 9 적용
```

## Claude가 할 일

1. **헷지가 의미 있는 조건** 체크리스트 (각 ✓/✗ + 한 줄 근거):
   - 연 매입 금액이 헷지 거래 비용 대비 충분히 큼 (보통 100억 원 이상이 효율적, 회사별 다름)
   - 가격 변동성 σ이 회사 마진을 잠식할 수준 (예: 영업이익률 5% < σ × 매입 비중)
   - 장기 공급 계약이 어려운 구조 (단기 시장 거래 비중 높음)
   - 재무팀의 헷지 회계 처리 역량
   - 헷지로 보호할 위험이 명확히 분리됨 (혼합 위험 헷지는 어렵다)
2. 위 체크리스트 결과로 **🟢 강추 / 🟡 부분 적용 / 🔴 불필요** 판정.
3. 적용한다면 다음 매핑:
   - 환율 위험 → KRW/USD forward (시중은행) 또는 FX option
   - 원자재 위험 → 거래소 상장 (cotton, oil, etc.) 또는 공급사 forward 계약
   - 가격 자체 → OTC forward (공급사와 N개월 단가 고정)
4. **하지 말아야 할 것**: 변동성이 작은 SKU에 헷지 비용 지불, 단일 SKU 헷지로 회사 전체 위험 해결 시도, 투기 목적 헷지.
5. **다음 단계** — 회사 재무팀에 가져갈 질문 3-5개 (회계, 신용 위험, 거래 상대방, 베이시스 위험 등).

## 출력 형식
markdown. 체크리스트 → 판정 → 매핑 표 → 하지 말 것 → 재무팀 질문.

## 가드레일
- **이 분석은 교육 목적이며 투자·헷징 권유가 아닙니다**라는 면책을 첫 줄에.
- Black-Scholes의 가정(변동성 일정, 무차익 등)은 단순화임을 명시.
- 학생이 \"그냥 헷지 들어가\"라고 해도 거절. 재무팀·회계법인 검토가 선행되어야 함을 강조.
- 회사 외부에 공유 금지 알림.
