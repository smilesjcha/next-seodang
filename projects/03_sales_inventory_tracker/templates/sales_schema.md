# sales.csv 스키마

본인 회사 매출 데이터를 다음 컬럼 형태로 `data/sales.csv`에 저장하세요.

| 컬럼 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `date` | YYYY-MM-DD | 매출 발생 일자 (또는 일별 집계 일자) | 2025-04-01 |
| `product_id` | string | 상품 식별자 (SKU 또는 사내 코드) | SKU-A001 |
| `product_name` | string | 상품 이름 (선택) | "라이트 셔츠 화이트 M" |
| `category` | string | 카테고리 (선택) | "셔츠" |
| `units_sold` | int | 판매 수량 | 12 |
| `revenue` | float | 매출액 (원, 부가세 포함 또는 일관성 있게) | 540000 |
| `channel` | string | 판매 채널 (선택, 예: "온라인", "오프라인", "도매") | 온라인 |

## 최소 요건

- `date`, `product_id`, `units_sold`, `revenue` 4개는 **필수**.
- 일자별·상품별로 **한 행**. 같은 일자/상품의 여러 채널은 별도 행으로 분리.
- 누락치는 빈 셀로 (NaN). 0으로 채우지 말 것 — 노트북이 누락과 0 매출을 구분합니다.

## 권장 기간

- 최소 **12개월 이상**의 데이터가 있어야 계절성 탐지가 가능.
- 18-24개월이면 ARIMA 예측 품질이 더 좋음.

## 보안

- `data/` 폴더는 `.gitignore`로 git 추적 차단됨.
- 외부에 공유 시 `product_id` 익명화, 절대 매출액을 그대로 공유하지 말 것.
