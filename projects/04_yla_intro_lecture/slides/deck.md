# YLA 학습 = 5단계 반복

| 단계 | 학생 활동 | AI의 자리 |
|---|---|---|
| 읽기 | 고전 정독 | 시대 배경·핵심 개념 설명 |
| 쓰기 | 보고서 직접 | 구조 점검·논리 피드백 |
| 말하기 | 발표 PPT | **사전 체크리스트** 후 초안 |
| 토론 | 조별 합의 | 반론·예상 질문 |
| 수정 | 피드백 반영 | 항목 분해·우선순위 |

> AI는 학생의 사고를 **대신**하지 않고, **다음 단계**로 넘어가도록 돕는다.

# Use case 1: 토요일 발표 준비

- **상황**: 다음 토요일 『논어』 3분 개인 발표

## 직장인 구매 — 매입 단가 분석

# Use case 3: 본인 회사 매입가 한 번 들여다보기

- **상황**: \"가격이 올랐다\"는 한 마디 안의 4가지 다른 원인
- **흐름**: STL 분해 → 매입 시그널 → 파생상품 payoff
- **20분 안에 도달**: 매입 적기 ___월, 헷지 의미 신호등

---

# 가격 상승의 4가지 원인

| 원인 | 합리적 행동 |
|---|---|
| **추세** (지속적) | 장기 계약·연간 단가 협상 |
| **계절성** (반복) | 비수기에 미리 매입 |
| **잔차 충격** (일회성) | 일시 대기 후 평균 회귀 |
| **매크로** (FX·유가) | 헷징, 결제 통화 변경 |

> STL 분해 4패널이 이 4개를 한 화면에 분리해 보여준다.

---

# 파생상품 — 보험 같은 도구

- **Forward**: 미래 가격 고정 (상승 막음, 하락도 못 누림)
- **Call option**: 매입 권리 (상승 cap + 하락 누림 + 프리미엄 비용)
- **패션 산업**: 상장 옵션 거의 없음 → OTC forward·FX 옵션·원자재 선물로 매핑

> ⚠️ 교육 목적. 실제 헷지는 회사 재무·법무팀 검토 필요.
