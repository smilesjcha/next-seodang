# Slide Templates — 7 유형 카탈로그

각 유형은 Marp의 `<!-- _class: <name> -->` directive로 적용합니다. 새 슬라이드를 만들 때 \"이건 어떤 유형인지\"를 먼저 결정한 뒤 해당 클래스를 지정하세요.

---

## 1. 표지 (`.title`)

**언제**: 강의 첫 장 1번만.

**구성**:
- 큰 강의 제목 (h1, 52pt)
- 부제 (h2, 22pt, 회색)
- 발표자·일자 (본문)

```markdown
<!-- _class: title -->

# Claude로 사고를 증폭하다

## YLA 학생·졸업생을 위한 1시간 도구 가이드

차성재 · 2026-04-26 · 아름다운서당
```

---

## 2. 섹션 분리 (`.section`)

**언제**: use case 1·2·3 진입 전 각 1장.

**구성**:
- 큰 번호 (h1, 64pt) — \"01\", \"02\", \"03\"
- 섹션 이름 (h2, 28pt, 강조색)

```markdown
<!-- _class: section -->

# 02

## 연구보고서 도우미 — 대학원생
```

---

## 3. 본문 단일 (기본, 클래스 지정 안 함)

**언제**: 가장 많이 사용. 슬라이드의 80%.

**구성**:
- 슬라이드 제목 (h1, 좌측 정렬, accent underline)
- bullet 3-5개 (본문)

```markdown
# YLA 5단계 학습과 AI의 자리

- **읽기** — 배경지식 이해 (AI: 진입 장벽 완화)
- **쓰기** — 직접 초안 (AI: 구조 점검)
- **말하기** — PPT 발표 (AI: 초안 생성, 체크리스트로 보호)
- **토론** — 조별 토의 (AI: 반론·합의 정리)
- **수정** — 피드백 반영 (AI: 항목 분해)
```

---

## 4. 본문 좌우 (`.split`)

**언제**: 좌측 메시지 + 우측 차트·이미지·코드.

**구성**: 두 column이 자동 분할.

```markdown
<!-- _class: split -->

# create-ppt(yla)의 사전 체크리스트

## 학생을 무시하지 않는 가드레일

- 보고서가 없으면 PPT 생성 거절
- 학생 본인의 관점이 비어 있으면 진행 안 함
- 빠진 항목은 placeholder로 표시

---

![checklist screenshot](../assets/checklist.png)
```

(Marp에서 `---` 한 줄이 column 분리.)

---

## 5. 인용 강조 (`.quote`)

**언제**: Hook 슬라이드, 핵심 메시지 1개를 크게 보일 때.

**구성**: 큰 인용 (36pt, 가운데). 발언자나 출처는 본문 작게.

```markdown
<!-- _class: quote -->

> AI는 학생의 사고를 대체하지 않는다.
> AI는 학생의 사고를 증폭한다.

— 이 강의의 출발점
```

---

## 6. 코드 / 출력 (`.code`)

**언제**: Claude 호출 명령, 노트북 셀, 터미널 명령어.

```markdown
<!-- _class: code -->

# 학생이 입력하는 한 줄

```
create-ppt(yla) — 다음 보고서로 발표 PPT 만들어줘.

발표 형식: 3분 개인 발표
보고서: <첨부>
```
```

(코드 블록 안의 백틱은 적절히 escape.)

---

## 7. 마무리 (`.closing`)

**언제**: 강의 마지막. \"감사합니다 / Q&A\" 1장.

```markdown
<!-- _class: closing -->

# 감사합니다.

질문은 카페 또는 sungjae@example.com
```

---

## 유형 결정 가이드

| 슬라이드 메시지 | 추천 유형 |
|---|---|
| 표지 / 마지막 | `title` / `closing` |
| use case 진입 | `section` |
| 한 메시지를 크게 강조 | `quote` |
| 텍스트만 (bullet) | 기본 |
| 텍스트 + 이미지/차트 | `split` |
| 코드·명령어·출력 | `code` |

**80/20 원칙**: 강의 16장 중 12장은 기본 유형, 나머지 4장이 표지/섹션/quote/closing. `split`이나 `code`는 정보 밀도가 필요한 1-2장에만.
