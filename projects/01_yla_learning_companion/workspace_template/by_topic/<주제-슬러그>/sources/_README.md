# sources/

이 주제와 관련된 **1차 자료**를 출처별로 1개 파일씩 모읍니다.

## 파일 명명 규칙

- 책: `book_<저자>_<짧은-책명>.md` (예: `book_plato_republic.md`)
- 논문: `paper_<저자>_<연도>.md`
- 기사·웹: `web_<출처>_<짧은-제목>.md`

## 각 파일의 표준 구조

```markdown
# <제목>

| | |
|---|---|
| 출처 | <전체 인용 형식> |
| 읽은 일자 | YYYY-MM-DD |
| 형식 | [ ] 종이 [ ] 전자책 [ ] PDF |

## 핵심 인용 (본인이 직접 발췌)

> \"...\"
- 위치: 페이지 N
- 본인 한 줄 반응:

(반복)

## 이 자료로 답한 질문

- 00_overview.md의 핵심 질문 #X에 어떻게 기여하나
```
