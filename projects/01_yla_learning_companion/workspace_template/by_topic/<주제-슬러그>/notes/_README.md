# notes/

**시간순 사고 흔적**. 본인이 이 주제를 생각할 때마다 새 파일.

## 파일 명명 규칙

`YYYY-MM-DD_<짧은-제목>.md` (예: `2026-04-15_first_thoughts.md`, `2026-04-22_synthesis_attempt.md`)

## 각 파일의 표준 구조

```markdown
# YYYY-MM-DD — <짧은 제목>

## 오늘의 자극
> 무엇이 이 사고를 일으켰나 (책의 한 구절 / 토론 / 일상 사건)

## 떠오른 생각 (raw)

## 정리 시도 (선택)

## 이 사고가 sources/ 어떤 자료와 연결되나

## 이 사고로 essays/ 또는 slides/ 어떤 버전이 영향받을까
```

> AI에 \"이 주제로 글 써줘\"가 아니라, 본인의 흐름을 누적하는 게 목적입니다.
