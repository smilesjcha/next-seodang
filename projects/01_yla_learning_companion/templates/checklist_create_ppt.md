# `create-ppt(yla)` 사전 체크리스트

이 체크리스트는 `create-ppt(yla)` 스킬이 호출되면 가장 먼저 출력됩니다. 학생이 PPT 작성에 필요한 재료가 준비되어 있는지 점검한 뒤에만 본 작업을 진행합니다.

```
PPT 작성에 필요한 재료가 준비되었는지 확인합니다.

[ ] 1. 발표 주제          (고전명 또는 사회 이슈)
[ ] 2. 발표 형식          (3분 개인 / 5분 조별)
[ ] 3. 본인이 작성한 보고서·에세이  ← 필수. 없으면 PPT 생성을 중단합니다.
[ ] 4. 핵심 주장 1문장     (보고서에서 추출 또는 별도 정리)
[ ] 5. 주요 근거 3개       (각 근거의 출처·인용 위치)
[ ] 6. 토론 쟁점           (찬성/반대/합의) — 조별 토론을 거친 경우만
[ ] 7. 현대 사회 적용점    (AI 시대·리더십·조직·사회 문제와 연결)
[ ] 8. 발표자 본인의 관점  (자기 해석 — AI가 대신하지 않는 부분)
```

## 분기 규칙

| 상태 | 행동 |
|---|---|
| 항목 3 ✗ | **PPT 생성을 거절**한다. 학생이 먼저 보고서를 작성하도록 `outline-essay(yla)` 또는 [docs/yla/02_learning_process.md](../../../docs/yla/02_learning_process.md) 안내. |
| 항목 8 ✗ | "발표자 본인의 관점이 비어있어 PPT를 만들 수 없습니다. 한 문장이라도 직접 적어주세요"라고 학생에게 묻고, 답이 오면 진행. |
| 항목 1·2·4·5·7 중 일부 ✗ | 부족한 항목을 한 번 더 묻거나, 학생 동의 시 명확한 placeholder(`[학생 보완 필요: ...]`)로 표시 후 진행. |
| 항목 6 ✗ | 조별 토론 전이면 정상. 그대로 진행. |
| 모두 ✓ | 발표 시간에 따라 슬라이드 수 결정 (3분 → 3-4장, 5분 → 5-6장) 후 본 작업. |
