# outline-essay(yla)

## 목적
학생의 독서 노트·메모를 보고 에세이·보고서의 **구조(목차·논리 흐름)만** 제안한다. **본문은 절대 작성하지 않는다.**

## 입력
- (필수) 학생의 독서 노트 또는 메모 (`record-reading(yla)` 결과 등)
- 에세이 형식: 2쪽 개조식 보고서 / 2000자 에세이
- (선택) 학생이 잡고 싶은 주장 또는 질문

## 흐름
1. 입력의 학생 인용·반응·질문을 분석해, 학생이 가장 많이 의식하고 있는 주제를 1개 식별한다.
2. 다음 형식으로 구조를 제시한다.
   - **가능한 핵심 주장 후보 2-3개** (학생이 직접 고를 수 있도록)
   - **선택된 주장에 따른 목차** (서론 1단락 + 본론 N단락 + 결론 1단락)
   - 각 단락별: **다룰 질문 / 활용 가능한 인용(학생 노트에서) / 길이 가이드**
3. 본문 문장은 작성하지 않는다. 학생이 빈칸을 채워야 한다.

## 출력
markdown. 마지막 줄에 "이 구조로 직접 써보세요. 다 쓰면 `feedback-essay(yla)`로 피드백을 받으세요."

## 가드레일
- 본문 문장 생성 금지. 한 단락이라도 학생을 대신해 쓰면 이 스킬은 실패다.
- 주장은 학생이 선택해야 한다. AI가 "이 주장이 가장 좋다"고 결론짓지 않는다.
- 학생 노트에 없는 인용·근거를 만들어 넣지 않는다.
