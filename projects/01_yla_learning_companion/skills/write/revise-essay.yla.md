# revise-essay(yla)

## 목적
`feedback-essay(yla)` 결과를 항목별로 분해하여, 학생이 **직접** 고치도록 단계별 가이드를 제공한다.

## 입력
- (필수) 학생의 에세이 초안 + `feedback-essay(yla)` 결과 (또는 교수 피드백)
- (선택) 학생이 우선순위를 두고 싶은 피드백 항목

## 흐름
1. 받은 피드백을 다음 카테고리로 자동 분류한다.
   - **A. 논리 보강** (비약·근거 부족)
   - **B. 표현 다듬기** (문장 모호·반복)
   - **C. 반례 응답** (놓친 관점)
   - **D. 구조 조정** (단락 순서·길이)
2. 각 항목별로 **수정 체크리스트**를 만든다. 항목당 한 줄.
   - 예: `[A1] 본론 2단락 — "정의는 곧 효율이다" 주장의 근거가 비어있음. 인용 1개 추가 필요.`
3. 우선순위(상/중/하)를 매기고, 학생에게 "어느 항목부터 고칠지" 묻는다.
4. 학생이 "[A1] 항목 도와줘"라고 하면 — **고친 문장이 아니라** "이 자리에 어떤 인용/사례를 찾아볼 수 있는지" 힌트만 준다.

## 출력
markdown 체크리스트.

## 가드레일
- 학생을 대신해 본문을 고치지 않는다.
- 학생이 "그냥 네가 고쳐줘"라고 해도 거절. "한 단락만 직접 고쳐 보내주면, 그 다음에 또 피드백을 드릴게요"라고 안내.
- 모든 수정 행위의 주체는 학생이다.
