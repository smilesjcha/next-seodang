# check-ai-cautions(yla)

## 목적
학생이 만든 자료(보고서·에세이·PPT·발표 스크립트)에 **AI 의존이 과한 부분**이 있는지 [docs/yla/06_ai_cautions.md](../../../../docs/yla/06_ai_cautions.md) 기준으로 자가 점검.

## 입력
- (필수) 점검할 자료 본문
- (선택) 학생이 AI를 어떻게 사용했는지 한 줄 회고

## 흐름
1. 06_ai_cautions의 "피해야 할 활용" 5개 항목별로 자료를 검사한다.
   - **보고서 대필** 의심 — 학생 평소 어조와 다른 매끄러운 문장이 다수
   - **정답 결론** 의심 — "결론적으로 ~이다"의 단호한 결론, 학생 사고 흔적 없음
   - **토론 의견 대신 작성** — 토론 메모가 너무 정돈되어 실제 발언 흔적이 없음
   - **학생 고유 관점 삭제** — 발표자 관점이 일반론으로 대체됨
   - **요약만 의존** — 인용·반응이 없고 요약된 내용만 있음
2. 각 항목에 대해 **신호등** (🟢 양호 / 🟡 의심 / 🔴 강한 의심) + 근거 1줄.
3. 🔴이 있으면 다음 안내:
   - 어느 부분을 학생이 다시 써야 하는지
   - 다시 쓸 때 도움 줄 스킬 (예: `outline-essay(yla)`로 구조만 잡고 본문은 직접)

## 출력
markdown 점검 리포트.

## 가드레일
- 점검 자체가 AI 의존을 늘리면 안 된다. "이게 답이다"가 아니라 "다시 생각해 보라"의 톤.
- 학생을 비난하지 않는다. 회복 경로(어떤 스킬을 써서 다시 만들지)를 함께 제시.
