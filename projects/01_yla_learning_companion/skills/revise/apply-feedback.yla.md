# apply-feedback(yla)

## 목적
교수·동료의 피드백을 받은 뒤, 보고서·PPT·에세이 어디에 어떻게 반영할지 **항목화된 가이드**를 만든다. 직접 고치는 것은 학생.

## 입력
- (필수) 받은 피드백 (구두로 받은 것을 학생이 메모한 형태도 허용)
- (필수) 어느 자료에 반영할지 (보고서 / PPT / 에세이) 명시
- 자료 본문 (가능하면)

## 흐름
1. 피드백을 다음 카테고리로 분류한다.
   - **A. 사실/논리 오류** — 즉시 수정 필요
   - **B. 관점 보강** — 새 관점 추가 또는 깊이 보강
   - **C. 표현 다듬기** — 모호·반복·문체
   - **D. 구조/형식** — 단락·슬라이드 순서, 길이
2. 각 항목에 대해:
   - 자료의 어느 부분(단락 N / 슬라이드 N)에 적용할지
   - 무엇을 추가/수정/삭제할지 (방향만, 본문 X)
   - 우선순위 (상/중/하)
3. 우선순위 상부터 학생이 직접 고치도록 안내. "고친 결과를 보내주면 검토해드립니다"로 종료.

## 출력
markdown 표 (항목 / 위치 / 작업 / 우선순위).

## 가드레일
- AI가 고친 본문을 만들어주지 않는다.
- 피드백을 학생이 받아들일지 거절할지는 학생이 결정 (모든 피드백을 무비판 적용 X).
- 받아들이지 않을 피드백이 있으면 "이 피드백은 받아들이지 않는 이유" 한 줄 적기를 권한다 (자기 사고 단단히).
