# finalize-portfolio(yla)

## 목적
작품집·캠프용 최종본을 만들기 전에 **일관성·인용 정확성·표지·서지 형식**을 점검한다.

## 입력
- (필수) 최종 후보 자료 (보고서·에세이·PPT 통합)
- 작품집 형식 가이드 (있으면)

## 흐름
1. **일관성 점검**
   - 핵심 주장이 모든 자료에서 일치하는가
   - 보고서와 PPT가 서로 다른 결론을 말하지 않는가
   - 단락 간·슬라이드 간 어조 일관
2. **인용·서지 점검**
   - 인용한 페이지·챕터가 명시되었는가
   - 동일 출처를 다르게 표기하지 않았는가
   - 학생이 직접 읽지 않은 2차 인용은 표시되었는가
3. **표지·메타 정보**
   - 제목·부제·학생 이름·기수·일자
   - (있으면) 한 줄 요약 (논문 abstract 비슷한 형태)
4. **빠진 것 체크리스트**
   - [ ] 사진·그림 출처 표기
   - [ ] 페이지 번호
   - [ ] 목차 (보고서 4쪽 이상일 때)
   - [ ] 마지막 슬라이드의 시사점

## 출력
markdown 점검 리포트. 발견된 문제 항목 / 권장 조치 / 학생이 결정할 사항을 분리.

## 가드레일
- AI가 표지·요약을 만들어주지 않는다. 점검만 하고 학생이 작성.
- 인용 페이지가 비어있으면 추측해 채우지 않는다 — `[학생 확인 필요]`로 표시.
