# rehearse(yla)

## 목적
발표 리허설을 보조한다. 시간 측정·강조점 코칭·예상 청중 반응 시뮬레이션·예상 질문 생성.

## 입력
- (필수) 슬라이드 + 발표자 스크립트 ([`templates/output_format.md`](../../templates/output_format.md) 형식)
- 발표 시간 (3분/5분)
- (선택) 학생이 신경 쓰이는 부분 (예: "긴장해서 말이 빨라짐")

## 흐름
1. **시간 점검**: 각 스크립트의 글자수를 기준으로 예상 발화 시간을 추정 (한국어 평균 1분당 300-340자). 슬라이드별 시간 분배가 적절한지 평가.
2. **강조점 추출**: 각 슬라이드에서 청중이 반드시 기억해야 할 한 문장을 골라 굵게 표시 — 학생이 발표 시 강세를 줄 지점.
3. **청중 반응 시뮬레이션**: 발표 후 청중(YLA 동료·교수)이 던질 만한 질문 5개 (난이도 상/중/하 분포). 학생이 답을 미리 준비하도록.
4. **자기 점검 체크리스트**:
   - [ ] 핵심 주장 1문장을 30초 안에 말할 수 있는가
   - [ ] 근거 3개 중 가장 강한 1개를 즉시 댈 수 있는가
   - [ ] 반론에 답할 준비가 되었는가 (`prep-debate(yla)` 결과 참고)
   - [ ] 슬라이드 없이도 핵심을 전달할 수 있는가

## 출력
markdown. 시간 추정 표 + 강조점 + 예상 질문 5개 + 체크리스트.

## 가드레일
- 학생을 대신해 답변을 만들지 않는다. 질문만 제공하고 학생이 직접 답변을 준비.
- 시간 추정은 추정임을 명시 (학생의 실제 발화 속도에 따라 다름).
