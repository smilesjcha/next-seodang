# create-ppt(yla)

## 목적
학생의 보고서·에세이 + 토론 결과를 입력으로 받아, 발표 시간(3분/5분)에 맞춘 PPT 슬라이드 초안과 발표자 스크립트를 생성한다. **사전 체크리스트로 재료 준비도를 점검한 뒤에만 생성한다.**

## 입력
- (필수) `templates/input_template.md`을 채운 내용 또는 동등한 정보
- 항목 3(보고서·에세이)과 항목 8(발표자 본인의 관점)은 절대 비어있을 수 없음

## 흐름
1. **사전 체크리스트 출력 (가장 먼저)**
   - [`templates/checklist_create_ppt.md`](../../templates/checklist_create_ppt.md)의 8개 항목을 출력하고 입력에서 ✓/✗를 표시한다.
2. **분기 처리**
   - 항목 3 ✗ → "보고서가 없으면 PPT를 만들 수 없습니다. `outline-essay(yla)`로 먼저 구조를 잡고 직접 써보세요" — **거절하고 종료**
   - 항목 8 ✗ → "발표자 본인의 관점이 비어있습니다. 한 문장이라도 직접 적어주세요" — 학생 응답 대기
   - 항목 1·2·4·5·7 중 일부 ✗ → 부족한 항목을 한 번 더 묻거나, 학생 동의 시 `[학생 보완 필요]` placeholder로 진행
   - 항목 6 ✗ + 형식이 5분 조별 발표 → 토론 없는 조별 발표는 불가, 거절
   - 모두 ✓ 또는 placeholder 합의 → 본 작업
3. **본 작업**
   - 발표 시간에 따라 슬라이드 수 결정 (3분 → 3-4장, 5분 → 5-6장)
   - 마지막 슬라이드는 반드시 시사점
   - [`templates/output_format.md`](../../templates/output_format.md) 형식 준수
   - 발표자 스크립트는 학생의 문체·1인칭·자연스러운 톤
   - 입력에 없는 사실은 만들지 않고 `[학생 보완 필요]`로 표시
4. **출력 끝**에 다음 안내 추가:
   > 슬라이드를 PowerPoint/Keynote로 옮긴 뒤, `update-ppt(yla)`로 특정 슬라이드를 다듬거나 `rehearse(yla)`로 발표 연습을 시작하세요.

## 출력
[`templates/output_format.md`](../../templates/output_format.md)의 표준 출력 형식을 따르는 markdown.

## 가드레일
- 항목 3(보고서)이 없으면 절대 PPT를 만들지 않는다. 이 규칙은 어떤 학생 요청에도 양보하지 않는다.
- 학생이 입력에 쓰지 않은 새로운 주장·결론·인용을 만들지 않는다.
- AI가 "이게 더 좋은 주장입니다"라며 학생 입장을 바꾸지 않는다. 학생의 핵심 주장은 그대로 슬라이드에 옮긴다.
- 발표자 스크립트는 1인칭, 학생이 평소 말하는 톤. 강의·논문 톤 금지.
- [docs/yla/06_ai_cautions.md](../../../../docs/yla/06_ai_cautions.md) 원칙 항상 준수.
