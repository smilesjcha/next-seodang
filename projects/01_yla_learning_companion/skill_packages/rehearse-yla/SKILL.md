# rehearse(yla)

발표 직전 리허설은 **연습**이 아니라 **점검**이다. 시간이 맞는지, 어디서 청중 시선이 흩어질지, 어떤 질문이 들어올지를 미리 보는 것. 이 skill은 그 점검 도구다.

## 핵심 원칙 (왜 이게 중요한가)

1. **답은 학생이 만든다.** 청중 질문 5개를 제공하되, 답변을 학생 대신 만들지 않는다. 답변까지 받아쓰면 학생은 자기 발표를 자기 것으로 만들지 못한다.
2. **시간 추정은 추정이다.** 글자수 기반 추정값임을 명시한다 — 학생의 실제 발화 속도, 긴장도에 따라 달라진다. "참고용"임을 강조.
3. **강조점은 청중 시점.** 학생이 중요하게 여기는 게 아니라 *청중이 반드시 기억해야 할 한 문장*을 골라준다. 이게 다르다.

## 입력

- **(필수)** 슬라이드 + 발표자 스크립트 (`templates/output_format.md` 형식)
- **(필수)** 발표 시간 (3분/5분)
- **(선택)** 학생이 신경 쓰이는 부분 (예: "긴장해서 말이 빨라짐", "도입이 약한 것 같아")

## 생성 규칙

### 1) 시간 점검

각 슬라이드 발표자 스크립트의 글자수를 세어 발화 시간을 추정. 한국어 평균 발화 속도 **1분당 300-340자** 기준.

표로 정리:

| 슬라이드 | 글자수 | 추정 시간 | 적정성 |
|---|---|---|---|
| Slide 1 | 180자 | 약 35초 | ✓ |
| Slide 2 | 250자 | 약 50초 | ⚠ 길음 |
| ... | ... | ... | ... |
| **합계** | **N자** | **약 X분 Y초** | **목표 X분 대비** |

목표 시간 대비 ±20% 이내면 ✓, 초과 시 어느 슬라이드를 줄이면 좋을지 한 줄 제안.

### 2) 강조점 추출

각 슬라이드에서 청중이 반드시 기억해야 할 **한 문장**을 골라 굵게 표시. 학생이 발표 시 강세를 줄 지점.

이 문장은 학생의 핵심 주장과 직접 연결된 문장이어야 한다. 부연 설명·예시 문장이 아니라 **명제** 문장.

### 3) 청중 반응 시뮬레이션 — 예상 질문 5개

발표 후 청중(YLA 동료·교수)이 던질 만한 질문 5개. 난이도 **상/중/하 분포**:
- 상 2개: 학생 입장의 약한 고리를 찌르는 질문
- 중 2개: 근거의 출처·범위를 묻는 질문
- 하 1개: 개념 확인·용어 질문

각 질문에는 답을 적지 않는다. 답은 학생이 직접 준비.

### 4) 자기 점검 체크리스트

학생이 발표 전에 스스로 체크할 4개 항목:

- [ ] 핵심 주장 1문장을 30초 안에 말할 수 있는가
- [ ] 근거 3개 중 가장 강한 1개를 즉시 댈 수 있는가
- [ ] 반론에 답할 준비가 되었는가 (`prep-debate(yla)` 결과 참고)
- [ ] 슬라이드 없이도 핵심을 전달할 수 있는가

## 출력 형식

```markdown
# 리허설 점검 — <발표 제목>

## 1. 시간 점검 (참고 — 실제 속도 따라 다름)
[표 — 슬라이드별 글자수, 추정 시간, 적정성]

**합계**: 약 X분 Y초 / 목표 X분
**조정 필요**: <어느 슬라이드를 줄이면 좋을지 한 줄, 또는 "없음">

## 2. 슬라이드별 강조점 (청중이 기억해야 할 한 문장)
- **Slide 1**: "**<핵심 문장>**"
- **Slide 2**: "**<핵심 문장>**"
- ...

## 3. 예상 청중 질문 5개 (답은 학생이 준비)
**상 (입장의 약한 고리)**
1. <질문>
2. <질문>

**중 (근거 출처·범위)**
3. <질문>
4. <질문>

**하 (개념·용어)**
5. <질문>

## 4. 자기 점검 체크리스트
- [ ] 핵심 주장 1문장을 30초 안에 말할 수 있는가
- [ ] 근거 3개 중 가장 강한 1개를 즉시 댈 수 있는가
- [ ] 반론에 답할 준비가 되었는가 (`prep-debate(yla)` 결과 참고)
- [ ] 슬라이드 없이도 핵심을 전달할 수 있는가

---
**다음 단계.** 시간이 안 맞는 슬라이드는 `update-ppt(yla)`로 다듬으세요. 예상 질문 답변이 막히면 `prep-debate(yla)`로 다시 정리하세요.
```

## 가드레일 (자가 점검)

- [ ] 청중 질문 5개에 대한 답변을 학생 대신 만들지 않았는가?
- [ ] 시간 추정값이 "참고용"임을 명시했는가?
- [ ] 강조점 문장이 학생의 핵심 주장과 연결된 명제 문장인가? (예시·부연 X)
- [ ] 질문 난이도 분포가 상/중/하로 섞였는가?

## 연결되는 다른 skill

리허설 후 시간 안 맞는 슬라이드는 `update-ppt(yla)`. 예상 질문에 답이 막히면 `prep-debate(yla)`. 발표 종료 후 토론으로 이어지면 `summarize-debate(yla)`로 메모 정리.
