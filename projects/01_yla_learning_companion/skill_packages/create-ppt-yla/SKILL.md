# create-ppt(yla)

발표 자료는 **학생의 보고서가 슬라이드 형태로 변환된 것**이어야 한다. AI가 보고서 없는 상태에서 PPT를 만들면 그것은 학생의 발표가 아니라 AI의 발표다. 그래서 이 skill은 사전 체크리스트가 가장 먼저다.

## 핵심 원칙 (왜 이게 중요한가)

1. **보고서 없으면 PPT 없다.** 항목 3(보고서·에세이)이 비어있으면 절대 진행하지 않는다. 어떤 학생 요청에도 양보하지 않는다 — 이 규칙이 무너지면 AI가 학생 대신 발표를 만드는 셈.
2. **새 주장·결론·인용 생성 금지.** 입력에 없는 사실을 만들어 슬라이드에 넣지 않는다. 부족한 자리는 `[학생 보완 필요]`로 표시.
3. **학생 핵심 주장을 그대로 옮긴다.** "이게 더 좋은 주장입니다"라며 학생 입장을 바꾸지 않는다. 어조·표현 다듬기까지만.
4. **발표자 스크립트는 1인칭, 학생 톤.** 강의·논문 톤 금지. 학생이 평소 말하는 것처럼 자연스럽게.

## 입력

- **(필수)** `templates/input_template.md`을 채운 내용 또는 동등한 정보 (8개 항목)
- 항목 3(보고서·에세이)과 항목 8(발표자 본인의 관점)은 **절대 비어있을 수 없음**

입력 8개 항목:
1. 발표 주제
2. 발표 형식 (3분 개인 / 5분 조별)
3. 본인이 작성한 보고서·에세이 (필수)
4. 핵심 주장 1문장
5. 주요 근거 3개
6. 토론 쟁점 (5분 조별일 때 필수)
7. 현대 사회 적용점
8. 발표자 본인의 관점 (필수)

## 흐름

### Step 1) 사전 체크리스트 출력 (가장 먼저)

`templates/checklist_create_ppt.md`의 8개 항목을 출력하고 입력 상태를 ✓/✗로 표시한다.

### Step 2) 분기 처리

- **항목 3 ✗** → "보고서가 없으면 PPT를 만들 수 없습니다. `outline-essay(yla)`로 먼저 구조를 잡고 직접 써보세요." **거절하고 종료.**
- **항목 8 ✗** → "발표자 본인의 관점이 비어있습니다. 한 문장이라도 직접 적어주세요." 학생 응답 대기.
- **항목 1·2·4·5·7 중 일부 ✗** → 부족한 항목을 한 번 더 묻거나, 학생 동의 시 `[학생 보완 필요]` placeholder로 진행.
- **항목 6 ✗ + 형식이 5분 조별 발표** → 토론 없는 조별 발표는 불가, 거절.
- **모두 ✓ 또는 placeholder 합의** → Step 3으로.

### Step 3) 본 작업

- 발표 시간에 따라 슬라이드 수: **3분 → 3-4장**, **5분 → 5-6장**
- 마지막 슬라이드는 **반드시 시사점(현대 사회 적용 + 발표자 관점)**
- `templates/output_format.md` 형식 준수
- 발표자 스크립트는 학생의 1인칭, 자연스러운 톤
- 입력에 없는 사실은 만들지 않고 `[학생 보완 필요]`로 표시
- 학생 핵심 주장(항목 4)은 그대로 슬라이드에 옮김

### Step 4) 출력 끝에 다음 안내 추가

> 슬라이드를 PowerPoint/Keynote로 옮긴 뒤, `update-ppt(yla)`로 특정 슬라이드를 다듬거나 `rehearse(yla)`로 발표 연습을 시작하세요. 토론을 앞두고 있다면 `prep-debate(yla)`로 예상 반론을 준비하세요.

## 출력 형식

```markdown
## 사전 체크리스트 결과
[표 — 8개 항목 + ✓/✗ + 부족분 표시]

진행: <상태 한 줄>

---

# <발표 제목>
## 슬라이드 N장 / 발표 시간 X분 / 형식 (개인/조별)

---

### Slide 1. <헤드라인>
- <bullet 1>
- <bullet 2>
- <bullet 3>

**발표 스크립트 (X초)**
> <학생 1인칭 자연스러운 톤>

---

### Slide 2. ...
...

---

### Slide N. (마지막 — 시사점)
...

---
**다음 단계.** [위 안내]
```

## 가드레일 (자가 점검)

- [ ] 항목 3(보고서)이 ✗인데도 PPT를 만들지는 않았는가? (절대 양보 금지)
- [ ] 입력에 없는 새 주장·인용·사실을 만들어 넣지는 않았는가? (모르면 `[학생 보완 필요]`)
- [ ] 학생의 핵심 주장(항목 4)을 그대로 옮겼는가? (바꾸지 않았는가)
- [ ] 발표자 스크립트가 1인칭·학생 톤인가? (강의·논문 톤 X)
- [ ] 마지막 슬라이드가 시사점인가?
- [ ] [`docs/yla/06_ai_cautions.md`](../../../../docs/yla/06_ai_cautions.md) 원칙을 어기지 않았는가?

## 연결되는 다른 skill

PPT 초안이 나오면 `update-ppt(yla)`로 특정 슬라이드 다듬기, `rehearse(yla)`로 시간·전달력 점검, `prep-debate(yla)`로 토론 준비.
