# finalize-portfolio(yla)

작품집·캠프 제출 직전, 자료가 여러 개 쌓여 있을 때 가장 자주 발생하는 문제는 **자료 간 불일치**다 — 보고서 결론과 PPT 결론이 미묘하게 다르거나, 같은 인용을 두 자료에서 다르게 표기하거나. 이 skill은 그 빈틈을 잡는다. 단, 빈틈을 *지적*만 한다.

## 핵심 원칙 (왜 이게 중요한가)

1. **AI가 표지·요약을 만들지 않는다.** 표지·서지·한 줄 요약은 학생이 직접 작성한다. 이 skill은 빠진 것·어긋난 것을 짚어주는 데서 멈춘다.
2. **인용 페이지 추측 금지.** 인용 페이지가 비어있으면 채우지 않는다. `[학생 확인 필요]`로 표시해 학생이 책을 다시 펴서 확인하게 한다.
3. **불일치 지적은 가치판단 없이.** "보고서 결론과 PPT 결론이 다르다"고 짚되, 어느 쪽이 맞다고 결정하지 않는다. 어느 쪽으로 통일할지는 학생이.

## 입력

- **(필수)** 최종 후보 자료 (보고서·에세이·PPT 통합. 가능하면 모두)
- **(선택)** 작품집 형식 가이드 (있으면 — 표지 형식, 페이지 번호 규칙 등)

## 생성 규칙

### 1) 일관성 점검

- 핵심 주장이 모든 자료에서 일치하는가
- 보고서와 PPT가 서로 다른 결론을 말하지 않는가
- 단락 간·슬라이드 간 어조가 일관되는가
- 같은 개념을 자료마다 다른 용어로 부르지 않는가

각 항목 결과를 **🟢 일관 / 🟡 미세 차이 / 🔴 어긋남**으로 표시 + 어디서 어떻게 어긋나는지 한 줄.

### 2) 인용·서지 점검

- 인용한 페이지·챕터가 명시되었는가
- 동일 출처를 자료마다 다르게 표기하지 않았는가 (예: 한 곳은 "플라톤 『국가론』 4권", 다른 곳은 "Plato Republic IV")
- 학생이 직접 읽지 않은 2차 인용은 표시되었는가 (예: "재인용: ...")

빈 인용은 `[학생 확인 필요: 페이지 미상]`으로.

### 3) 표지·메타 정보

다음 항목 존재 여부 체크:
- 제목·부제
- 학생 이름·기수
- 일자
- (있으면) 한 줄 요약 (논문 abstract 비슷)

빠진 항목은 `[학생 보완 필요]`로 — AI가 채우지 않음.

### 4) 빠진 것 체크리스트

- [ ] 사진·그림 출처 표기
- [ ] 페이지 번호
- [ ] 목차 (보고서 4쪽 이상일 때)
- [ ] 마지막 슬라이드의 시사점

## 가드레일 (자가 점검)

- [ ] 표지·한 줄 요약을 AI가 만들어주지 않았는가?
- [ ] 빈 인용 페이지를 추측해 채우지 않았는가? (`[학생 확인 필요]`)
- [ ] 자료 간 불일치를 지적할 때 어느 쪽이 맞다고 결정하지 않았는가? (학생 결정)
- [ ] 신호등(🟢🟡🔴)으로 결과를 명확히 표시했는가?

## 연결되는 다른 skill

🔴 항목을 보강할 때 — 자료별 내부 수정은 `revise-essay(yla)` / `update-ppt(yla)`. 외부 피드백 종합 반영은 `apply-feedback(yla)`. 마무리 전 AI 의존도 점검은 `check-ai-cautions(yla)`.
