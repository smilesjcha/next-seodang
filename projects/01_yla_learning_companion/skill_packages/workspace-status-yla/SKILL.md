# workspace-status(yla)

학생이 책 한 권의 학습을 진행하다 보면 `workspace/<책이름>/` 폴더에 노트·초안·슬라이드·메모가 뒤섞인다. 며칠 만에 돌아오면 "어디까지 했지?"부터 막힌다. 이 skill은 그 막힘을 풀어준다.

## 핵심 원칙 (왜 이게 중요한가)

1. **내용 평가 금지.** 자료의 좋고 나쁨을 평가하지 않는다. 존재 여부와 단계 진행도만. 평가는 다른 skill(`feedback-essay`, `check-ai-cautions`)이 한다.
2. **추천은 강요가 아니다.** 다음 액션을 1-3개 제시하되, 학생이 다른 단계로 건너뛰고 싶어하면 존중한다 — "꼭 순서대로 가야 하는 건 아닙니다".
3. **5단계 흐름 매핑.** 자료를 단계에 매핑해 보여주는 것이 핵심. 학생이 "지금 어디 있는지"를 시각적으로 파악할 수 있게.

## 입력

- **(필수)** `workspace/` 폴더 트리 (Claude Desktop이 읽을 수 있는 형태로 첨부 또는 filesystem MCP로 노출)
- **(선택)** 현재 학습 중인 책·주제 (지정하면 그 폴더만 점검)

## 생성 규칙

### 1) 자료 분류

`workspace/<책이름>/` 또는 `workspace/<주제>/` 안의 파일들을 다음 카테고리로 분류:

| 카테고리 | 파일명 패턴 |
|---|---|
| 독서 노트 | `reading_note_*.md` |
| 에세이 초안 | `essay_*.md` |
| PPT 슬라이드 | `slides_*.md` |
| 토론 메모 | `debate_*.md` |
| 피드백 기록 | `feedback_*.md` |

패턴에 안 맞는 파일은 "기타"로 분류, 학생에게 어느 카테고리인지 묻는다.

### 2) 5단계 진행도 표시

각 단계에 다음 신호 부착:
- ✅ 자료 있음 + 다음 단계로 넘어간 흔적 있음
- ⚠️ 자료 있으나 다음 단계가 막혀있음 (예: 초안만 있고 피드백·수정 흔적 없음)
- ⏳ 시작 안 함

```
[1] 읽기      ✅ 인용 N개, 질문 N개 (reading_note_*.md)
[2] 쓰기      ⚠️ 초안만 있고 피드백 미반영 (essay_*.md, feedback 없음)
[3] 말하기    ⏳ PPT 미작성
[4] 토론하기  ⏳ 토론 메모 없음
[5] 수정하기  ⏳
```

### 3) 다음 추천 액션 1-3개

진행도를 보고 다음에 무엇을 하면 좋을지 1-3개 제시. 각 액션에 **사용할 skill 이름** 명시.

추천은 막혀있는 곳을 풀어주는 것 위주:
- ⚠️가 있으면 그것부터 풀기
- ⏳만 있으면 학생이 가장 흥미를 가진 다음 단계로

### 4) 건너뛰기 존중

학생이 "토론은 건너뛰고 PPT부터 만들고 싶어"라고 하면 존중한다. 5단계가 강제 순서가 아님을 한 줄로 명시.

## 출력 형식

```markdown
# 워크스페이스 상태 — <책이름 또는 주제>

## 5단계 진행도

```
[1] 읽기      <상태> <근거>
[2] 쓰기      <상태> <근거>
[3] 말하기    <상태> <근거>
[4] 토론하기  <상태> <근거>
[5] 수정하기  <상태> <근거>
```

## 자료 목록

| 카테고리 | 파일 | 마지막 수정 |
|---|---|---|
| 독서 노트 | `reading_note_2025-04-20.md` | 2025-04-20 |
| 에세이 초안 | `essay_v1.md` | 2025-04-22 |
| ... | ... | ... |

(없는 카테고리는 표시 안 함)

## 다음 추천 액션 1-3개

1. **<액션 한 줄>** — `<skill 이름>` 사용
   - 왜: <한 줄>
2. ...
3. ...

> 5단계는 강제 순서가 아닙니다. 다른 단계부터 진행하고 싶으면 그렇게 하셔도 됩니다.
```

## 가드레일 (자가 점검)

- [ ] 자료 내용을 평가하지 않았는가? (존재 여부와 진행도만)
- [ ] 추천을 강요하지 않았는가? (1-3개 제시 + 건너뛰기 존중 명시)
- [ ] 각 단계 신호(✅/⚠️/⏳)에 근거를 한 줄 적었는가?
- [ ] 추천 액션마다 사용할 skill 이름을 명시했는가?

## 연결되는 다른 skill

이 skill 결과의 추천 액션에 따라 다음 skill이 결정된다 — `explain-classic(yla)`(읽기 시작), `record-reading(yla)`(노트 정리), `outline-essay(yla)`(쓰기 시작), `feedback-essay(yla)`(초안 점검), `create-ppt(yla)`(발표 자료), `prep-debate(yla)`(토론 준비), `summarize-debate(yla)`(토론 정리), `apply-feedback(yla)`(피드백 반영), `finalize-portfolio(yla)`(최종 점검), `check-ai-cautions(yla)`(자가 점검).
