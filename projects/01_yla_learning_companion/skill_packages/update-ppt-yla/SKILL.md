# update-ppt(yla)

PPT 초안이 한 번에 완성되는 일은 거의 없다. 발표 연습 중에 "이 슬라이드만 약하다"는 신호가 나오는데, 이때 **그 한 장만** 다시 만지는 도구가 필요하다. 다른 슬라이드를 건드리면 흐름이 무너진다.

## 핵심 원칙 (왜 이게 중요한가)

1. **지목한 슬라이드만.** 학생이 "Slide 3"이라고 하면 Slide 3만 손댄다. 옆 슬라이드가 이상해 보여도 건드리지 않는다 (슬라이드 간 흐름은 학생이 결정).
2. **핵심 주장 보존.** 학생의 주장을 바꾸지 않는다. 어조·표현·구조만 다듬는다.
3. **새 사실 금지.** 학생이 입력에 쓰지 않은 인용·사실을 추가하지 않는다. 부족하면 `[학생 보완 필요]`.

## 입력

- **(필수)** 기존 슬라이드 markdown (`templates/output_format.md` 형식 또는 학생이 직접 정리한 것)
- **(필수)** 어느 슬라이드를 어떻게 고치고 싶은지
  - 예: "Slide 3의 bullet이 너무 추상적, 구체 사례로 바꿔줘"
- **(선택)** 발표 리허설에서 받은 피드백, 시간 초과 여부

## 흐름

### Step 1) 슬라이드 식별

학생이 지목한 슬라이드를 찾는다. 지목이 없거나 모호하면 — "어느 슬라이드(번호)를 어떻게 고칠까요?"로 되묻는다.

### Step 2) 변경 의도 분류

다음 4개 카테고리 중 하나로 분류:

- **논리 보강** — bullet이 비약, 근거 부족
- **메시지 압축** — bullet이 너무 길거나 3개 초과
- **전환 자연스럽게** — 앞뒤 슬라이드와의 연결 끊김
- **스크립트 재작성** — 발표 시간이 안 맞거나 톤이 어색

### Step 3) 슬라이드 재작성

해당 슬라이드만 `templates/output_format.md` 형식으로 다시 작성. 다른 슬라이드는 건드리지 않는다.

- bullet 3개 이내 권장
- 발표 스크립트는 1인칭, 학생 톤
- 시간이 명시되었으면 글자수로 점검 (한국어 1분당 약 300-340자)

### Step 4) 변경 이유 한 줄

"왜 이렇게 바꿨는지" 한 줄로 명시. 학생이 동의/거부를 판단할 수 있게.

## 출력 형식

```markdown
## 변경 카테고리
**<논리 보강 / 메시지 압축 / 전환 자연스럽게 / 스크립트 재작성>**

## 변경된 Slide N

### Slide N. <헤드라인>
- <bullet 1>
- <bullet 2>
- <bullet 3>

**발표 스크립트 (X초)**
> <학생 1인칭 자연스러운 톤>

## 왜 이렇게 바꿨는가
<한 줄>

---
**다음 단계.** 이 변경이 마음에 들지 않으면 어디가 어색한지 알려주세요. 다른 슬라이드도 다듬고 싶으면 슬라이드 번호와 의도를 말씀해주세요.
```

## 가드레일 (자가 점검)

- [ ] 학생이 지목한 슬라이드만 손댔는가? (다른 슬라이드 건드리지 않았는가)
- [ ] 학생의 핵심 주장을 바꾸지 않았는가? (어조·표현 다듬기까지인가)
- [ ] 입력에 없던 새 사실·인용을 끼워넣지 않았는가?
- [ ] 변경 이유를 한 줄로 명시했는가?

## 연결되는 다른 skill

여러 슬라이드를 다듬은 뒤 `rehearse(yla)`로 전체 시간·전달력 점검. 발표를 앞두고 토론 가능성이 있으면 `prep-debate(yla)`로 반론 준비.
