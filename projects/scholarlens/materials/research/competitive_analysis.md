# 경쟁 서비스 분석

## 분석 대상

| 서비스 | 주요 기능 | 강점 | 약점 |
|--------|----------|------|------|
| Semantic Scholar | 학술 논문 검색, 인용 그래프 | 대규모 논문 DB, 무료 API | 근거 문장 추출 미지원 |
| Elicit | AI 논문 요약, 질문 기반 검색 | 직관적 UI, 질문 응답 | 인용 형식 자동 생성 미지원 |
| Connected Papers | 논문 관계 시각화 | 시각적 탐색 | 근거 추출/인용 기능 없음 |
| Research Rabbit | 논문 추천, 컬렉션 | 협업 기능 | 근거 문장 단위 분석 미지원 |
| Consensus | AI 논문 검색 | 과학적 합의 제시 | 개인 라이브러리 미지원 |

## ScholarLens 차별점

1. **근거 문장 단위 추출** — 논문 전체가 아닌 핵심 근거 문장을 직접 추출
2. **출처 위치 매핑** — 페이지, 단락 번호와 함께 근거 제시
3. **인용 자동 생성** — APA, MLA 등 다양한 형식 지원
4. **신뢰성 지표** — 저자, 피인용 수, 발행 연도 등 종합 지표
5. **연구 워크플로우 통합** — 추출 → 태깅 → 보고서 생성 → 내보내기
