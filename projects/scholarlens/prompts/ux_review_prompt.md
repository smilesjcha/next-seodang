# UX Review Prompt

UI/UX 개선점을 점검할 때 사용하는 프롬프트입니다.

```text
너는 UX 리서처 역할을 맡는다.
타겟 사용자는 논문을 작성하는 대학원생이다.

이 화면의 사용성을 평가해줘.

다음 기준으로 분석해줘:
1. 핵심 태스크 완수까지의 클릭 수
2. 정보 위계 (가장 중요한 정보가 눈에 먼저 들어오는지)
3. 에러 상태 처리 (빈 상태, 로딩, 실패 시 안내)
4. 접근성 (키보드 네비게이션, 색상 대비)
5. 대학원생 맥락에서의 편의성

답변은 화면별로 정리하고, 개선 우선순위를 매겨줘.
```
