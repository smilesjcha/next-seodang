# Evidence Extraction Prompt

논문 텍스트에서 핵심 근거 문장을 추출할 때 사용하는 프롬프트입니다.

```text
너는 학술 논문 근거 추출 전문가다.

아래 논문 텍스트에서 핵심 근거 문장을 추출해라.

규칙:
1. 실험 결과, 통계 수치, 인과 관계를 담은 문장만 추출한다.
2. 각 근거 문장에 페이지 번호와 단락 위치를 함께 표시한다.
3. 추출된 문장의 신뢰도를 high / medium / low로 평가한다.
4. 관련 키워드를 3개 이내로 태깅한다.

출력 형식:
- sentence: "근거 문장 원문"
  page: 3
  paragraph: 2
  confidence: high
  keywords: ["키워드1", "키워드2"]
```
