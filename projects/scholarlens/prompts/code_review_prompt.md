# Code Review Prompt

작성한 코드를 AI에게 리뷰받을 때 사용하는 프롬프트입니다.

```text
너는 시니어 풀스택 개발자 역할을 맡는다.

이 프로젝트 폴더의 코드를 리뷰해줘.

다음에 집중해줘:
1. 보안 취약점 (입력 검증, SQL 인젝션, XSS 등)
2. 성능 병목 (불필요한 재렌더링, N+1 쿼리 등)
3. 타입 안전성 (any 사용, 누락된 에러 처리 등)
4. 네이밍과 구조 (naming_governance.md 기준 준수 여부)
5. 테스트 누락 여부

답변은 파일별로 정리하고, 심각도를 critical / warning / suggestion으로 분류해줘.
```
