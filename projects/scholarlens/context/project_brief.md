# Project Brief

## 프로젝트명

ScholarLens — AI 기반 논문 근거 탐색 및 연구 효율화 솔루션

## 참여자

- 18기 철수

## 목적

- 논문 근거 탐색 시간을 70% 이상 단축한다.
- AI 기반 근거 추출과 신뢰성 검증으로 연구 품질을 높인다.
- 보고서 자동 생성으로 비연구 업무 부담을 줄인다.

## 이번 세션 주제

- 프로젝트 킥오프: PRD 검토 및 기술 스택 결정

## 청중

- 대학원생 (학위 논문 작성, 학회 발표 준비, 연구 프로젝트 수행)

## 원하는 산출물

- 논문 근거 추출 웹 서비스 (Next.js)
- 근거 문장 라이브러리 및 인용 관리 기능
- 연구 보고서 자동 생성 및 내보내기 기능
- 연구 동향 시각화 대시보드

## AI에게 기대하는 역할

- 논문 텍스트 파싱 및 근거 문장 추출
- 인용 형식 자동 생성 (APA, MLA)
- 근거 신뢰성 평가 (저자, 피인용 수 등)
- 연구 보고서 요약 및 초안 작성
- 시맨틱 검색을 통한 관련 근거 탐색

## 금지사항

- 사실 검증 없는 단정
- 원문 맥락을 무시한 요약
- 출처 없는 수치 생성
- 인용 정보의 임의 생성 (실제 메타데이터 기반만 허용)
