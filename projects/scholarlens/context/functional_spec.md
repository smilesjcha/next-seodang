## 1. AI 기반 근거 문장 탐색 및 추출

> 🔴 높음 | ⚪ 시작전

사용자가 업로드하거나 검색한 논문 내에서 핵심 근거 문장을 AI가 자동으로 식별하고 추출하여 제공합니다.

### 수용 기준

- [ ] PDF, DOCX 등 다양한 문서 형식에서 근거 문장을 정확히 추출할 수 있어야 한다
- [ ] 추출된 근거 문장은 원문 출처(페이지 번호, 단락 등)와 함께 제시되어야 한다
- [ ] 사용자가 특정 키워드나 주제로 근거 문장을 필터링하고 검색할 수 있어야 한다

### 1.1 다양한 문서 형식 지원

> 🔴 높음 | 사용자 | 데스크톱

PDF, DOCX, TXT 등 여러 문서 형식에서 AI가 핵심 근거 문장을 신속하고 정확하게 추출할 수 있도록 지원합니다.

**관련 코드 경로:**
- `app/src/ai/parsers/` — 문서 형식별 파서
- `app/src/app/papers/upload/` — 업로드 페이지
- `app/src/components/papers/file-dropzone.tsx` — 파일 드래그앤드롭 UI
- `app/storage/uploads/` — 원본 파일 저장

**데이터 흐름:**
```
사용자 업로드 → storage/uploads/ → ai/parsers/ → storage/processed/ → DB
```

### 1.2 정확한 근거 문장 위치 표시

> 🔴 높음 | 사용자 | 데스크톱

추출된 근거 문장을 원문 내 페이지 번호와 단락 번호 등 출처 정보와 함께 사용자에게 제공합니다.

**관련 코드 경로:**
- `app/src/ai/prompts/evidence-extraction.ts` — 근거 추출 프롬프트
- `app/src/components/evidence/source-location-badge.tsx` — 위치 표시 배지
- `app/src/components/papers/paper-viewer.tsx` — 원문 뷰어 (하이라이트 오버레이)

### 1.3 키워드 및 주제별 근거 문장 필터링

> 🔴 높음 | 사용자 | 데스크톱

사용자가 관심 있는 특정 키워드 또는 주제에 따라 추출된 근거 문장을 검색 및 필터링할 수 있는 기능을 지원합니다.

**관련 코드 경로:**
- `app/src/components/evidence/evidence-filter.tsx` — 필터 UI
- `app/src/ai/embeddings/search.ts` — 시맨틱 검색
- `app/src/server/api/routers/evidence.ts` — 필터 API

## 2. 근거 기반 인용 및 신뢰성 검증 지원

> 🔴 높음 | ⚪ 시작전

추출된 근거 문장에 대한 적절한 인용 형식을 제안하고, 해당 근거가 얼마나 신뢰할 수 있는지에 대한 정보를 제공합니다.

### 수용 기준

- [ ] APA, MLA 등 주요 인용 스타일 가이드에 맞춰 인용 형식을 자동 생성할 수 있어야 한다
- [ ] 추출된 근거 문장의 저자 정보, 발행 연도, 피인용 수 등 신뢰성 지표를 표시해야 한다
- [ ] 사용자가 추출된 근거 문장을 클릭하여 원문 맥락을 바로 확인할 수 있어야 한다

### 2.1 자동 인용 형식 생성기

> 🔴 높음 | 사용자 | 데스크톱

APA, MLA 등 주요 학술 인용 스타일에 맞춰 인용 정보를 자동으로 생성합니다.

**관련 코드 경로:**
- `app/src/ai/prompts/citation-generation.ts` — 인용 생성 프롬프트
- `app/src/components/citations/citation-format-selector.tsx` — APA/MLA 선택 UI
- `app/src/server/services/citation-service.ts` — 인용 포맷팅 로직

### 2.2 근거 신뢰성 지표 제공

> 🔴 높음 | 사용자 | 데스크톱

저자 정보, 발행 연도, 피인용 수 등 신뢰성을 객관적으로 평가할 수 있는 지표를 함께 제공합니다.

**관련 코드 경로:**
- `app/src/ai/prompts/reliability-scoring.ts` — 신뢰성 평가 프롬프트
- `app/src/components/citations/reliability-indicator.tsx` — 신뢰성 지표 UI

### 2.3 원문 맥락 즉시 확인 기능

> 🔴 높음 | 사용자 | 데스크톱

사용자가 근거 문장을 클릭하면 원문 논문 내의 문맥과 주변 내용을 즉시 확인할 수 있습니다.

**관련 코드 경로:**
- `app/src/components/papers/paper-viewer.tsx` — 원문 뷰어 (클릭 시 해당 위치 이동)
- `app/src/app/papers/[paperId]/page.tsx` — 논문 상세 페이지

## 3. 연구 데이터 시각화 및 관리

> 🟡 중간 | ⚪ 시작전

탐색된 근거 문장, 인용 정보, 관련 연구 동향 등을 시각적으로 정리하고, 개인 연구 라이브러리를 구축합니다.

### 수용 기준

- [ ] 핵심 키워드, 저자, 연도별 근거 문장 분포 등을 그래프 형태로 시각화하여 제공해야 한다
- [ ] 사용자가 추출된 근거 문장을 태그, 카테고리별로 분류하고 저장할 수 있어야 한다
- [ ] 저장된 근거 문장 및 논문을 검색, 편집, 삭제할 수 있는 기능을 제공해야 한다

### 3.1 연구 동향 트렌드 시각화

> 🟡 중간 | 사용자 | 데스크톱

관심 분야별 연구 동향과 핵심 키워드 변화를 시계열 그래프나 히트맵 형태로 시각화합니다.

**관련 코드 경로:**
- `app/src/app/visualize/page.tsx` — 시각화 페이지
- `app/src/components/visualize/trend-timeline.tsx` — 트렌드 타임라인
- `app/src/components/visualize/keyword-heatmap.tsx` — 키워드 히트맵

### 3.2 맞춤형 태그 및 카테고리 관리 기능

> 🟡 중간 | 사용자 | 데스크톱

사용자가 개인 연구 주제에 맞게 태그 및 카테고리를 생성, 편집, 삭제하고 근거 문장을 분류합니다.

**관련 코드 경로:**
- `app/src/app/library/page.tsx` — 라이브러리 페이지
- `app/src/server/api/routers/library.ts` — 태그/컬렉션 API

### 3.3 개인 연구 라이브러리 검색 및 편집 인터페이스

> 🟡 중간 | 사용자 | 데스크톱

저장된 근거 문장과 논문 자료를 키워드, 태그, 날짜 등 다양한 필터로 검색하고 편집할 수 있는 인터페이스를 제공합니다.

**관련 코드 경로:**
- `app/src/app/library/collections/` — 컬렉션 관리
- `app/src/hooks/use-evidence-filter.ts` — 필터 훅

## 4. 자동화된 연구 보고서 및 요약 생성

> 🟡 중간 | ⚪ 시작전

추출된 근거 문장들을 기반으로 연구 보고서 초안이나 요약문을 자동으로 생성합니다.

### 수용 기준

- [ ] 사용자가 보고서 템플릿을 선택하거나 사용자 정의하여 보고서를 생성할 수 있어야 한다
- [ ] 주요 근거 문장과 함께 자동으로 요약된 내용을 포함하여 보고서를 생성할 수 있어야 한다
- [ ] 생성된 보고서를 PDF, DOCX 등 다양한 형식으로 내보낼 수 있어야 한다

### 4.1 사용자 정의 보고서 템플릿 편집기

> 🟡 중간 | 사용자 | 데스크톱

연구 목적과 스타일에 맞춰 보고서 템플릿을 자유롭게 생성하고 편집합니다.

**관련 코드 경로:**
- `app/src/app/reports/new/page.tsx` — 보고서 생성 페이지
- `app/src/components/reports/report-template-picker.tsx` — 템플릿 선택 UI

### 4.2 자동 근거 요약 및 하이라이트 기능

> 🟡 중간 | 사용자 | 데스크톱

핵심 근거 문장을 자동으로 요약하고 보고서 내에서 하이라이트합니다.

**관련 코드 경로:**
- `app/src/ai/prompts/summarization.ts` — 요약 프롬프트
- `app/src/ai/chains/report-chain.ts` — 보고서 생성 체인
- `app/src/components/reports/summary-preview.tsx` — 요약 미리보기

### 4.3 다양한 형식별 보고서 내보내기

> 🟡 중간 | 사용자 | 데스크톱

PDF, DOCX, PPT 등 다양한 형식으로 변환 및 내보내기 기능을 제공합니다.

**관련 코드 경로:**
- `app/src/app/reports/[reportId]/page.tsx` — 보고서 뷰어/에디터
- `app/src/server/services/export-service.ts` — 내보내기 서비스
- `app/storage/exports/` — 생성된 파일 임시 저장
