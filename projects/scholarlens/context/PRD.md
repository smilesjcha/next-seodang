## 1. 개요

### 1.1 한 줄 정의

AI 기반 논문 근거 탐색 및 연구 효율화 솔루션

### 1.2 제품 목표

논문 작성 및 연구 과정에서 필요한 근거 정보를 AI 기반으로 신속하고 정확하게 탐색·추출하여:

- 연구 생산성 극대화
- 비연구 업무 부담 경감
- 근거 기반 의사결정 신뢰성 향상
- 새로운 연구 인사이트 및 발견 촉진

### 1.3 배경

- 연구자는 방대한 논문을 검토하며 **근거 문장 탐색에 많은 시간 소요**
- 근거의 신뢰성 확보를 위해 **수작업 검증 필수**
- 이로 인해 **정보 탐색 latency 증가**
- 메일, 엑셀 등 반복 업무로 **연구 외 업무 부담 증가**

---

## 2. 핵심 가치

### 2.1 사용자 문제

- 근거 기반 정보 탐색 시간이 과도하게 길다
- 수작업 검증으로 인해 신뢰성 확인이 어렵다
- 반복적인 비연구 업무로 인해 연구 집중도가 저하된다

### 2.2 해결 방식

- AI 기반 **근거 문장 탐색 및 추출**
- 논문 탐색 시간 **70% 이상 단축**
- 근거 기반 인용 정확도 향상 → 신뢰성 확보
- 자동화된 보고서 생성 및 연구 데이터 시각화 → 비연구 업무 최소화

### 2.3 차별점

| 구분 | 기존 검색 | ScholarLens |
|------|----------|-------------|
| 정보 제공 | 문서/논문 리스트 | 근거 문장 직접 추출 |
| 정확성 | 사용자 판단 의존 | AI 기반 정밀 추출 |
| 신뢰성 검증 | 수작업 | 자동 검증 지원 |
| 업무 지원 | 없음 | 연구 업무 자동화 |

> 단순 검색이 아닌 **근거 중심 Research Workflow 통합 솔루션**

## 3. 타겟 및 시나리오

### 3.1 타겟 사용자

**대학원생** (Primary Target)

| 특성 | 설명 |
|------|------|
| 주요 활동 | 논문 작성 및 연구 프로젝트 수행 |
| 부가 활동 | 학회 발표 자료 준비 |
| 제약 조건 | 제한된 시간 내 성과 압박 |
| 핵심 니즈 | 빠른 정보 탐색 및 검증 |

### 3.2 사용 시나리오: 논문 작성 과정

```
1. 사용자가 논문 PDF 업로드 또는 검색
2. AI가:
   - 핵심 근거 문장 추출
   - 관련 인용 정보 자동 제안
3. 사용자가:
   - 근거 문장 검토
   - 신뢰성 검증 도구 활용
4. 결과 활용:
   - 논문 직접 인용
   - 연구 노트 저장
   - 발표 자료 활용
```

> 결과: **논문 작성 속도 및 품질 동시 개선**

## 4. 성공 지표 (KPI)

| 지표 | 목표 |
|------|------|
| 논문 근거 탐색 시간 | 70% 이상 단축 |
| 근거 문장 추출 정확도 | 90% 이상 |
| AI 논문 검색 사용률 | 월 30% 이상 증가 |
| Lab Meeting 준비 시간 | 50% 이상 감소 |

## 5. 리스크 / 이슈

### 5.1 기술 리스크

- 근거 문장 추출 정확도 미흡 → 신뢰도 하락

### 5.2 시장 리스크

- 유사 서비스 등장 및 경쟁 심화

### 5.3 데이터 리스크

- 연구 데이터 보안
- 개인정보 보호 이슈

### 5.4 제품 리스크

- 복잡한 UI → 사용자 채택률 저하
- 학술 데이터 업데이트 및 유지 비용 증가

## 7. 요약

- **문제**: 연구자의 근거 탐색 + 검증 비용 과다
- **해결**: AI 기반 근거 중심 Research Workflow 자동화
- **핵심 가치**: 시간 단축 (70%), 정확도 향상 (90%), 연구 집중도 개선
- **성공 기준**: 탐색 시간 / 정확도 / 사용률 / 준비 시간
