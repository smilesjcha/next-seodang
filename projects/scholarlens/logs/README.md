# Logs

프로젝트 진행 과정의 토론 기록, AI 피드백 로그, 아키텍처 결정 기록을 보관합니다.

## 폴더 구조

- `decisions/` — 아키텍처 결정 기록 (ADR)
- 루트 — 주간 토론 및 AI 피드백 로그

## 파일 규칙

- 주간 로그: `week{NN}_{type}.md` (예: `week03_discussion.md`)
- AI 피드백: `week{NN}_ai_feedback.md`
- ADR: `ADR-{NNN}_{short_title}.md` (예: `ADR-001_database_choice.md`)
