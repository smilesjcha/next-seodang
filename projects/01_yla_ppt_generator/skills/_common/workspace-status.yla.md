# workspace-status(yla)

## 목적
`workspace/` 안의 학생 자료(독서노트·에세이 초안·PPT·토론 메모) 상태를 한눈에 본다. 다음에 무엇을 할지 결정하는 데 사용.

## 입력
- `workspace/` 폴더 트리 (Claude Desktop이 읽을 수 있는 형태로 첨부 또는 filesystem MCP로 노출)
- (선택) 현재 학습 중인 책·주제

## 흐름
1. `workspace/<책이름>/` 또는 `workspace/<주제>/` 안의 파일들을 다음 카테고리로 분류:
   - **독서 노트** (`reading_note_*.md`)
   - **에세이 초안** (`essay_*.md`)
   - **PPT 슬라이드** (`slides_*.md`)
   - **토론 메모** (`debate_*.md`)
   - **피드백 기록** (`feedback_*.md`)
2. 학습 단계 진행도를 5단계 흐름에 맞춰 표시.
   ```
   [1] 읽기      ✅ 인용 N개, 질문 N개
   [2] 쓰기      ⚠️ 초안만 있고 피드백 미반영
   [3] 말하기    ⏳ PPT 미작성 — `create-ppt(yla)` 권장
   [4] 토론하기  ⏳ 토론 메모 없음
   [5] 수정하기  ⏳
   ```
3. **다음 추천 액션 1-3개** + 각 액션에 사용할 스킬 이름.

## 출력
markdown 진행도 표 + 추천 액션.

## 가드레일
- 자료 내용을 평가하지 않는다. 존재 여부와 단계 진행도만.
- 추천은 강요가 아니다. 학생이 다른 단계로 건너뛰고 싶어하면 존중.
