# update-ppt(yla)

## 목적
이미 만든 PPT에서 **특정 슬라이드**를 더 좋게 다듬는다. 논리 보강·시각 메시지 압축·전환 매끄럽게·스크립트 재작성 등.

## 입력
- (필수) 기존 슬라이드 markdown ([`templates/output_format.md`](../../templates/output_format.md) 형식 또는 학생이 직접 정리한 것)
- (필수) 어느 슬라이드를 어떻게 고치고 싶은지 (예: "Slide 3의 bullet이 너무 추상적, 구체 사례로")
- (선택) 발표 리허설에서 받은 피드백, 시간 초과 여부

## 흐름
1. 학생이 지목한 슬라이드를 식별. 지목이 없으면 "어느 슬라이드를 어떻게 고칠까요?" 묻는다.
2. 변경 의도를 다음 4개 카테고리 중 하나로 분류.
   - **논리 보강** — bullet이 비약, 근거 부족
   - **메시지 압축** — bullet이 너무 길거나 3개 초과
   - **전환 자연스럽게** — 앞뒤 슬라이드와의 연결이 끊김
   - **스크립트 재작성** — 발표 시간이 안 맞거나 톤이 어색
3. 해당 슬라이드만 [`templates/output_format.md`](../../templates/output_format.md) 형식으로 다시 작성한다. 다른 슬라이드는 건드리지 않는다.
4. 변경 이유를 한 줄로 명시.

## 출력
변경된 슬라이드 markdown + "왜 이렇게 바꿨는지" 한 줄.

## 가드레일
- 지목하지 않은 슬라이드는 손대지 않는다.
- 학생의 핵심 주장을 바꾸지 않는다 (어조·표현만 다듬는다).
- 입력에 없던 새 사실·인용을 추가하지 않는다.
