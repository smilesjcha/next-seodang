# literature_synthesis(rr)

## 목적
🟢 핵심 인용으로 분류된 논문들을 **연구 질문 관점에서 합성**한다. 각 논문 요약을 나열하는 게 아니라, 논문들 사이의 **합의·대립·공백**을 드러낸다.

## 사용법

```
literature_synthesis(rr) — 다음 논문들을 합성해 문헌 리뷰를 작성해줘.

연구 질문:
<한 문장>

대상 논문 (reference_quality_check에서 🟢로 분류된 것들):
1. [제목, 저자, 연도]
   abstract: ...
   학생 본인이 본문에서 발견한 핵심: ... ← 학생이 직접 읽고 채운 부분 (필수)
2. ...
```

## Claude가 할 일

1. 학생이 "본문에서 발견한 핵심"을 채우지 않은 논문이 있으면 **합성을 거절**한다. "abstract만으로는 합성하지 않습니다. 본문을 읽고 핵심을 한 줄 적은 뒤 다시 호출해주세요."
2. 모든 논문이 채워졌다면 다음 구조로 합성:
   - **합의된 발견** (multiple papers point to ...)
   - **상충하는 결과** (Paper A says X, Paper B says Y, Paper C reconciles by ...)
   - **방법론적 차이**
   - **공백** (어떤 질문이 아직 답을 받지 못했는가)
   - **연구 질문에 대한 잠정 답변** — 학생이 가설로 다듬을 출발점
3. 모든 주장에 인용 표기 `[Author Year]`. 인용 없이 추정·일반론 금지.

## 출력 형식
markdown 5개 섹션. 마지막에 "이 합성은 가설을 위한 출발점입니다. 본문을 다시 확인하고 의문점을 추가 조사하세요" 안내.

## 가드레일
- 학생이 본문을 읽지 않은 채 abstract로만 합성하려 하면 거절.
- 입력에 없는 논문·인용·통계를 만들지 않는다.
- "연구 질문에 대한 답"을 단정짓지 않는다 — "잠정 답변·가설"로 표현.
- 인용은 입력에 명시된 형태로만 (저자 환각 금지).
