# report_outline(rr)

## 목적
`literature_synthesis(rr)` 결과 + 학생의 연구 질문을 받아, **연구보고서 목차**(섹션/하위 섹션/예상 분량)를 생성한다. 본문은 작성하지 않는다.

## 사용법

```
report_outline(rr) — 보고서 목차를 만들어줘.

연구 질문:
<한 문장>

문헌 합성 결과:
<literature_synthesis 결과 markdown>

보고서 형식:
- 분량: <예: 30쪽 본문>
- 종류: <학기말 보고서 / 논문 / 학회 발표문 / 기말 발표 자료>
- 인용 양식: <APA / MLA / Chicago / 자유>
```

## Claude가 할 일

1. 다음 표준 구조를 베이스로 학생 형식에 맞게 조정:
   - 1. 서론 (배경·연구 질문·기여)
   - 2. 문헌 리뷰 (합의·대립·공백)
   - 3. 연구 방법 (필요 시)
   - 4. 분석/논의
   - 5. 결론 (한계·후속 연구)
2. 각 섹션에 다음 명시:
   - 다룰 핵심 질문 1-2개
   - 활용할 핵심 인용 (literature_synthesis에서 인용한 논문)
   - 예상 분량 (전체 분량 비례)
3. 전체 분량 합이 입력한 보고서 분량과 ±10% 이내인지 확인.
4. **본문 문장 작성 금지** — 학생이 빈칸을 채워야 한다.

## 출력 형식
markdown 목차 + 분량 분배 표 + "본문은 학생이 직접 채워주세요" 안내.

## 가드레일
- 본문 문장을 만들지 않는다.
- 학생의 연구 질문이나 합성 결과에 없는 인용을 추가하지 않는다.
- 학생이 "그냥 본문도 써줘"라고 해도 거절. "한 섹션만 직접 써서 보내주면 피드백을 드릴게요."
