# reference_quality_check(rr)

## 목적
`02_score_quality.ipynb`의 정량 점수(인용수·연도) 위에, Claude의 **정성 평가**를 더한다. "이 논문이 진짜 내 연구 질문에 답을 주는가"라는 관점.

## 사용법

```
reference_quality_check(rr) — 다음 논문 후보들을 평가해줘.

내 연구 질문:
<topic_scoping에서 좁힌 한 문장>

논문 후보 (notebooks/02_score_quality 결과):
<markdown 표 또는 CSV 붙여넣기>
- 제목, 저자, 연도, 인용수, 정량점수, abstract
```

## Claude가 할 일

1. 각 논문에 대해 다음 4개 축으로 평가:
   - **관련성** (★ 1-5) — 연구 질문에 직접 답하는가, 간접 인용 수준인가
   - **신뢰성** (★ 1-5) — 저자·저널·인용 패턴, 동료심사 여부
   - **재현성/방법론** (★ 1-5) — 실험·데이터·방법론이 명확한가
   - **차별성** (★ 1-5) — 다른 후보들과 겹치지 않는 독자적 기여
2. 각 별점에 한 줄 근거.
3. **분류 결과**:
   - 🟢 핵심 인용 (반드시 직접 읽고 인용)
   - 🟡 보조 인용 (필요 시 인용, 본문은 핵심만 확인)
   - 🔴 후보 제외 (관련성 낮음 또는 신뢰성 부족)
4. **빠진 관점** 안내: "이 후보 셋만으로는 X 측면이 부족합니다. 추가 검색 키워드 제안 — Y, Z"

## 출력 형식
markdown 표 (논문 / 4개 별점 / 분류 / 한 줄 코멘트) + 빠진 관점 섹션.

## 가드레일
- abstract만 보고 평가했음을 명시. 학생이 본문을 직접 확인해야 한다는 점 강조.
- "이 논문은 결정적입니다" 같은 단정 금지. 학생이 판단할 자료를 제공.
- AI가 임의로 만든 평가 항목·인용 수 등 숫자 환각 금지 — 입력에 있는 데이터만 사용.
