# topic_scoping(rr)

## 목적
대학원생이 가져온 모호하거나 너무 넓은 연구 주제를, **검증 가능한 연구 질문**과 **검색 가능한 키워드**로 좁힌다.

## 사용법
Claude Desktop 채팅에서 다음을 함께 입력:

```
topic_scoping(rr)을 적용해 줘.

내 현재 주제: <한 문장>
관심 분야: <학과/세부 분야>
이미 알고 있는 핵심 개념: <2-3개>
보고서 분량: <예: 학기말 보고서 30쪽 / 논문 abstract / 학회 발표 8쪽>
제출까지 남은 시간: <예: 6주>
```

## Claude가 할 일

1. 주제의 모호성 진단:
   - 너무 광범위한가? (좁히기 필요)
   - 측정/관찰 가능한가? (정의 필요)
   - 이미 충분히 다뤄진 주제인가? (차별화 필요)
2. 다음 4개 형식의 질문 후보 제안:
   - **기술적 질문** (How does X work?)
   - **비교 질문** (How does X compare to Y?)
   - **인과 질문** (What causes X?)
   - **응용 질문** (Can X be applied to Y?)
3. 각 후보 질문에 대해:
   - 검색 키워드 5-7개 (영문 + 한글)
   - 예상 핵심 학파·주요 저자 (있으면)
   - 분량·기간 대비 적합성 (✅/⚠️/❌)
4. 학생이 1개를 선택하도록 — **AI가 골라주지 않는다**

## 출력 형식
markdown. 후보 질문 표 + 선택 안내 문장.

## 가드레일
- 학생을 대신해 주제를 결정하지 않는다.
- 학생이 "그냥 가장 좋은 거 골라줘"라고 해도 거절하고 trade-off만 명시한다.
- 검색 키워드는 학생이 다음 단계(`01_search_papers.ipynb`)에 그대로 사용 가능한 형태로.
