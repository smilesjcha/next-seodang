# Claude로 사고를 증폭하다

## YLA 재학·졸업생을 위한 1시간 도구 가이드

차성재 · 2026-04-26 · 아름다운서당

---

<!-- _class: quote -->

> AI는 학생의 사고를 대체하지 않는다.
> AI는 학생의 사고를 **다음 단계**로 넘긴다.

— 이 강의의 출발점

---

# 오늘의 약속

- 슬라이드를 보고 끝나는 게 아니라, **본인 컴퓨터에서 직접 실행**한다
- 3가지 use case 중 **본인에게 가까운 1개**를 1주 안에 본인 자료로 적용
- AI가 학생을 무시하지 않게 만든 **가드레일을 직접 체험**한다

---

# 잠깐 — \"AI\"라는 게 뭔가요?

처음 보시는 분도 계실 테니 30초만.

- **AI** = 사람이 쓴 텍스트 수억 페이지를 학습해, 글 형태의 \"다음 한 줄\"을 생성하는 도구
- **답변 기계가 아닌 \'사고 증폭기\'** — 잘 쓰면 본인 사고가 더 깊어지고, 잘못 쓰면 본인 사고가 사라짐
- 대표 도구: ChatGPT(OpenAI), Gemini(Google), **Claude(Anthropic)** ← 오늘의 도구

> 다른 AI도 비슷하게 작동. 오늘은 **Claude를 한 번 깊게** 써본다.

---

# 왜 Claude인가 — 3가지 이유

**1. 길게 읽는다**
보고서 한 권, 논문 10편, 폴더 통째로 컨텍스트로 받는다 (1M 토큰 = 책 7권 분량)

**2. 사고를 안 빼앗는다**
\"보고서 대신 써줘\"보다 \"구조만 잡아줘\"에 더 잘 따라온다 — 우리가 만든 가드레일을 안정적으로 지킨다

**3. 한 두뇌가 여러 자리에 들어간다**
채팅, 코딩, 팀 협업, 디자인 — 4개의 진입점이 **같은 컨텍스트 위에서** 일관되게 작동

---

# Claude의 4가지 진입점

| 진입점 | 자리 | 누구에게 |
|---|---|---|
| **Claude Desktop / Web** | 채팅 + 폴더 컨텍스트 | 모든 사용자 (오늘 강의의 메인) |
| **Claude Code** | 터미널 + 코드 자동화 | 노트북·반복 작업 다루는 사람 |
| **Claude Cowork** | Slack·Linear 등 팀 도구 연결 | 직장에서 팀 협업하는 졸업생 |
| **Claude Design** *(2026-04-17 발표, Pro/Max/Team/Enterprise)* | 디자인·시각 작업 | 발표 자료·one-pager 자주 만드는 사람 |

> 같은 AI 두뇌, 들어가는 자리가 다를 뿐.

---

# Claude Design — 9일 전 발표된 신규 진입점

- **무엇**: 텍스트·이미지·문서를 입력 → \"러프 아웃라인 → 완성된 brand-on deck\"을 분 단위로
- **두뇌**: Claude Opus 4.7 비전 모델 (가장 강력한 시각 모델)
- **수정 방식**: 인라인 댓글 / 직접 편집 / 슬라이더 — 채팅창보다 디자이너 친화적
- **디자인 시스템 학습**: 팀 코드·디자인 파일 한 번 읽고 → 이후 모든 결과물에 색·폰트·컴포넌트 자동 적용
- **Export**: Canva · PDF · PPTX · HTML · 내부 공유 URL
- **연결**: 디자인 → Claude Code로 바로 개발 단계 이관

> Figma 주가가 발표 당일 -7%. \"누가 디자이너 필요한가\"라는 헤드라인까지 나온 만큼의 충격.

# 진입점별 — 인문 학생 입장의 예

| 진입점 | YLA 학생의 상황 | 한 줄 예시 |
|---|---|---|
| Desktop | 보고서 첨부 → PPT 슬라이드 markdown | \"create-ppt(yla)\" |
| Code | 논문 검색 노트북을 다시 돌리기 | \"이 키워드로 OpenAlex 재검색\" |
| Cowork | YLA 카페 지난주 토론 정리 | \"이 채널 글들 5문장 요약\" |
| Design | 이번 토요일 발표 자료 시각 톤 통일 | \"이 보고서로 brand-on PPTX 만들어줘\" |

> 같은 학생이, 같은 한 주에, 4개 자리를 모두 만난다.
> 오늘 deck도 사실 Claude Design으로 만들 수 있는데, 우리는 일부러 마크다운+Marp로 만들어 **\"코드 한 곳, 모든 슬라이드\"** 의 단일 출처 원칙을 보여드린다.

# 학생 사고를 보호하는 두 장치

## 1. 가드레일

`create-ppt(yla)`는 **8개 사전 체크리스트**를 먼저 출력한다.

- 보고서 없으면 → 거절
- 학생 본인의 관점 비어 있으면 → 응답 대기
- 부족 항목은 placeholder 표시

---

## 2. 본문 미작성

`outline-essay(yla)`는 구조만, 본문 한 줄도 안 쓴다.

- 서론·본론·결론의 자리만
- 인용 출처 위치만
- 본문은 학생이 직접 채워야 함

# Use case 3 : 본인 회사 매입가 들여다보기

- **상황**: \"가격이 올랐다\"는 한 마디 안의 4가지 원인
- **흐름**: STL 분해 → 매입 시그널 → 파생 payoff diagram
- **20분 안에 도달**: 매입 적기 ___월, 헷지 의미 신호등
- **샘플 데이터 36개월** 기본 제공 — 회사 데이터 없어도 흐름 동일

---

# 가격 상승의 4가지 원인

| 원인 | 합리적 행동 |
|---|---|
| **추세** (지속적) | 장기 계약·연간 단가 협상 |
| **계절성** (반복) | 비수기 미리 매입 |
| **잔차 충격** (일회성) | 일시 대기 후 평균 회귀 |
| **매크로** (FX·유가) | 헷징, 결제 통화 변경 |

> STL 4패널 한 화면이 이 4개를 분리해 보여준다.
