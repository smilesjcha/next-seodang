# next_seodang

`next_seodang`는 아름다운서당 및 넥스트서당 강의/실습/문서 자산을 정리하는 저장소다.

이 레포의 목적은 세 가지다.

1. 아름다운서당/넥스트서당 참여자들의 실제 업무 및 학습 맥락에서 AI 활용 니즈를 구조적으로 정리한다.
2. AI Native 시대의 직무 변화, Multiplier 역량, Agent 활용 방식을 강의 자료로 체계화한다.
3. 학생들이 직접 따라 해볼 수 있는 문서, 프롬프트, 실습 코드, 에이전트 구조 예제를 누적 가능한 형태로 관리한다.

## Repository Map

- `docs/`
  - 강의 전략, 설문 분석, 학생용 가이드, 슬라이드 아웃라인
- `workshops/`
  - 강의 운영안, 실습 진행안, Colab 실습 안내
- `examples/`
  - Python 기반 최소 Agent 예제와 함수 호출 데모
- `agents/`
  - Agent 개념 설명 및 역할별 설계 문서
- `skills/`
  - 재사용 가능한 skill 문서 템플릿과 강의용 skill 정의
- `prompts/`
  - 강의, 실습, 리서치, 케이스스터디 운영용 프롬프트 자산
