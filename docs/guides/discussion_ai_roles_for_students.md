# 아름다운서당 학생용 토론/토의 AI 활용 가이드

## 이 문서의 목적

아름다운서당 학생들이 인문학, 경영학, 케이스스터디, 프로젝트 발표를 준비하는 과정에서 AI를 어떤 역할로 기대하면 좋은지 정리한다.

핵심은 간단하다.

- AI는 의견을 대신 내는 주체가 아니다.
- AI는 `생각을 더 선명하게 만들고`, `논의를 더 밀도 있게 만들고`, `팀 협업의 마찰을 줄이는 조율 도구`다.

## 회의록 기준으로 이번 교육에서 특히 중요한 역할

회의록에 나온 핵심 방향은 다음 세 가지다.

1. `AI Facilitator`
   - 토론 조율, 의견 통합, 갈등 해결, 합의 도출
2. `Socratic Tutor`
   - 답변 대신 질문으로 사고를 밀어주는 역할
3. `Cognitive Partner`
   - 문제 정의, 탐색, 반론, 리허설을 함께하는 사고 파트너

아래 역할 설명은 이 세 방향을 학생 활동에 맞게 풀어쓴 것이다.

## AI에게 기대할 수 있는 5가지 역할

### 1. 사회자 보조

AI는 토론의 흐름을 잡아주는 보조 사회자 역할을 할 수 있다.

- 지금까지 나온 논점을 3줄로 정리
- 중복 발언과 새로운 쟁점 구분
- 남은 시간 기준으로 다음 질문 제안
- 특정 참가자의 발언이 부족할 때 균형 질문 제안

### 2. 피드백 코치

AI는 발표자나 발언자에게 더 나은 피드백을 줄 수 있다.

- 논리 비약이 있는지 점검
- 주장과 근거가 연결되는지 확인
- 표현이 너무 추상적인지 지적
- 청중이 반박할 만한 포인트 예측

### 3. 반론 생성자

토론이 한 방향으로만 흐를 때 AI는 반대편 관점을 생성해줄 수 있다.

- 이 주장에 대한 가장 강한 반론 3개
- 윤리적/현실적/경제적 관점에서 반대 논리 제시
- 우리가 놓친 이해관계자 관점 추가

### 4. 논점 정리자

회의가 길어질수록 사람이 놓치는 구조를 AI가 정리할 수 있다.

- 지금까지의 핵심 쟁점 정리
- 찬성/반대 논리 분류
- 합의된 내용 vs 미합의 내용 구분
- 다음 회차에 이어갈 질문 도출

### 5. 리허설 상대

발표와 토론은 사전에 부딪혀보는 것이 중요하다.

- 예상 질문 생성
- 꼬리 질문 생성
- 발표의 약한 부분을 공격적으로 질문
- 청중 수준별 질문 분화

## 담당 역할별로 AI에 기대하면 좋은 것

## 1. 발제자 / 발표자

발제자는 "내용 정리"보다 "논리 설계"에 AI를 써야 한다.

AI에게 기대할 것:

- 발제문 요약이 아니라 핵심 주장 구조화
- 발표 슬라이드 흐름 점검
- 예상 질문 10개 생성
- 가장 취약한 논점 지적
- 소크라테스식 질문으로 주장 자체를 다시 생각하게 만들기

추천 프롬프트:

```text
너는 날카로운 세미나 리뷰어다.
아래 발제 초안을 읽고
1. 핵심 주장 3개
2. 논리 비약 지점
3. 청중이 물을 가능성이 높은 질문 10개
4. 발표자가 보강해야 할 부분
을 정리하라.
```

## 2. 사회자 / 진행자

사회자는 AI를 통해 토론 흐름을 설계하고 균형을 잡을 수 있다.

AI에게 기대할 것:

- 오프닝 질문 설계
- 발언 균형을 위한 추가 질문
- 논점이 산만해질 때 재정렬 문구 생성
- 마무리 정리 멘트 생성
- 합의 여부를 확인하는 체크 질문 생성

추천 프롬프트:

```text
너는 대학 세미나 사회자 보조다.
아래 주제와 참여자 구성을 바탕으로
1. 오프닝 질문 3개
2. 토론이 막혔을 때 던질 질문 5개
3. 논점이 옆길로 샜을 때 다시 중심으로 돌리는 멘트
4. 마무리 정리 멘트
를 작성하라.
```

## 3. 피드백 담당

피드백 담당은 AI를 통해 비판을 더 구조화할 수 있다.

AI에게 기대할 것:

- 주장, 근거, 사례, 전달력 기준으로 피드백 틀 생성
- 감정적 표현을 줄이고 구체적 피드백으로 변환
- 칭찬과 개선점을 균형 있게 정리
- 과정 중심 평가 기준에 맞게 피드백 구조화

추천 프롬프트:

```text
아래 발표/토론 내용을 읽고
1. 좋았던 점
2. 더 선명해질 수 있는 점
3. 추가 질문이 필요한 부분
4. 다음 발표 전에 보완할 점
을 구체적으로 정리하라.
```

## 4. 기록 담당

기록 담당은 AI를 가장 즉각적으로 활용할 수 있다.

AI에게 기대할 것:

- 회의록 요약
- 액션아이템 정리
- 핵심 문장 추출
- 다음 회차 준비사항 정리
- 토론 로그를 이후 아카이빙 가능한 형식으로 정리

## 5. 프로젝트 리더

프로젝트 리더는 AI를 결과 생성기보다 `구조 설계 파트너`로 쓰는 것이 중요하다.

AI에게 기대할 것:

- 문제 정의 문장 다듬기
- 프로젝트 범위 축소/확장 판단 보조
- 주차별 계획 초안
- 역할 분담 초안
- 중간 점검 질문 생성

## 학생들이 주의해야 할 점

1. AI가 정리한 반론이나 요약을 그대로 믿지 말 것
2. 원문 텍스트와 실제 발언 맥락을 다시 확인할 것
3. 토론의 목표가 정답 찾기가 아니라 사고 확장이라는 점을 잊지 말 것
4. AI를 쓰면 더 빨라질 수 있지만, 더 깊어지려면 사람이 검토해야 한다

## 가장 좋은 사용 방식

가장 좋은 방식은 다음 순서다.

1. 먼저 사람끼리 1차 토론
2. 그 다음 AI로 논점 정리와 반론 보강
3. 마지막으로 다시 사람끼리 수정 토론

즉, AI는 시작점이 아니라 `중간 증폭기`로 쓰는 편이 좋다.

## 교육 철학과 연결한 한 줄 정리

아름다운서당에서 AI는 `생각을 대신하는 존재`가 아니라, `생각을 더 멀리 밀어주는 조력자`로 두는 것이 맞다.
