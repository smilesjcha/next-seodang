# 아름다운서당 20기 학생 활동용 AI Playbook

## 어디에 도움을 줄 수 있는가

학생들이 인문학, 경영학, 케이스스터디, 외부 활동을 직접 운영할 때 AI는 다음 역할에서 특히 유용하다.

1. `리서치 압축`
   - 책, 아티클, 기업 자료, 인터뷰 자료를 빠르게 구조화
2. `토론 설계`
   - 세션 아젠다, 질문지, 반론 포인트 생성
3. `운영 자동화`
   - 공지문, 참석 확인, 회의록 정리, 역할 분배
4. `결과물 정리`
   - 발표안, 요약문, 인사이트 메모, 후속 액션 정리

## 활동별 활용 예시

### 인문학 세션

- 읽을 텍스트의 핵심 주장 3개 추출
- 토론 질문 7개 생성
- 반대 해석 3개 제안
- 현대 사회/커리어와 연결되는 적용 질문 생성

### 경영학 세션

- 특정 프레임워크 요약
- 기업 사례를 SWOT, 3C, STP, JTBD로 재구성
- 발표자별 역할 분담 초안 생성

### 케이스스터디

- 케이스 배경 요약
- 의사결정 포인트 정리
- 찬반 양측 주장 정리
- 발표용 1페이지 executive summary 생성

### 대외활동 운영

- 공지문 초안
- 회의록 요약
- 액션아이템 정리
- 행사 후 후기/회고 정리

## 학생들이 꼭 익혀야 할 서비스

### 기본형

- ChatGPT
  - 사고 파트너, 초안 생성, 요약, 구조화
- Claude
  - 긴 문서 요약, 글쓰기, 맥락 유지
- Gemini
  - Google 생태계 연동, 빠른 아이디어 보조
- Google AI Studio
  - 프롬프트/구조화 실험, API 감각 익히기

### 실습형

- Google Colab
  - 코드 실습, 데이터 다루기, API 호출 시연
- GitHub
  - 문서/코드/프롬프트 자산 관리

### 생산성형

- Notion AI
  - 회의록, 문서 정리
- Perplexity
  - 탐색형 리서치와 출처 기반 검색

## 학생들에게 강조할 운영 원칙

1. AI는 "답"보다 "생각의 초안"을 받는 도구로 사용한다.
2. 반드시 검증 가능한 출처, 원문, 숫자 근거를 다시 확인한다.
3. 프롬프트를 길게 쓰는 것보다, 원하는 산출물 형식을 분명히 적는 것이 중요하다.
4. 한 번 잘 만든 프롬프트와 체크리스트는 팀 자산으로 축적한다.

## 팀 운영용 기본 프롬프트

### 세션 준비용

```text
너는 인문학/경영학 스터디 운영을 돕는 조교다.
아래 주제에 대해 1) 핵심 논점 3개, 2) 토론 질문 7개, 3) 반대 관점 3개, 4) 발표용 요약 1단락을 만들어라.

주제:
자료:
청중:
```

### 케이스스터디용

```text
너는 MBA 케이스스터디 조교다.
아래 케이스를 읽고 다음 형식으로 정리하라.
1. 상황 요약
2. 주요 이해관계자
3. 핵심 의사결정 포인트
4. 찬성 논리
5. 반대 논리
6. 토론 질문 5개
```

### 회의록 정리용

```text
아래 회의 내용을 바탕으로
1. 핵심 결정사항
2. 남은 쟁점
3. 담당자별 액션아이템
4. 다음 회의 전 준비사항
형식으로 정리하라.
```
