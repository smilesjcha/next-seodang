# AI 피드백 조율자/사회자 활용 노하우

## 목적

학생들이 토론, 세미나, 발표, 케이스스터디를 진행할 때 AI를 `피드백 조율자`, `사회자`, `리허설 파트너`로 쓰는 방법을 정리한다.

회의록의 핵심 방향인 `Result -> Process`, `Tool -> Cognitive Partner`를 실제 운영 문장으로 옮기는 문서다.

## 사회자로서 AI를 쓸 때

### AI에게 맡기면 좋은 일

- 발제 전에 질문 세트 만들기
- 토론 도중 논점 흐름 정리
- 참여자별 관점 차이 요약
- 마무리 단계에서 핵심 인사이트 정리
- 합의 형성 여부 확인
- 충돌 지점에서 중재 질문 제안

### AI에게 맡기면 안 좋은 일

- 누가 맞는지 판정하는 역할
- 토론 결론을 대신 확정하는 역할
- 맥락 없는 도덕적 평가

## 피드백 조율자로서 AI를 쓸 때

### 좋은 활용

- 피드백을 구조화한다.
- 너무 추상적인 감상을 구체적 개선 문장으로 바꾼다.
- 공격적 표현을 생산적 피드백으로 바꾼다.
- 결과보다 과정 기준으로 피드백을 재구성한다.

### 예시

- 나쁜 피드백:
  - "좀 별로였어요"
- AI를 거친 피드백:
  - "핵심 메시지가 1개로 모이지 않아 발표가 분산되어 들렸습니다. 첫 2분 안에 주장 한 줄을 더 명확히 제시하면 이해가 쉬워질 것 같습니다."

## 리허설 상대자로서 AI를 쓸 때

### 가장 유용한 방식

- 쉬운 질문 3개
- 까다로운 질문 3개
- 반대 관점 질문 3개
- 실무 연결 질문 3개

이 4종 세트로 준비하면 발표 완성도가 빠르게 올라간다.

## 팀별 운영 루틴

### 토론 전

- 자료 요약
- 핵심 질문 생성
- 반론 생성
- 참가자 역할별 준비 질문 생성

### 토론 중

- 메모 정리
- 논점 분류
- 다음 질문 추천
- 발언 편중 여부 점검

### 토론 후

- 피드백 구조화
- 다음 액션 정리
- 회고 요약
- DB에 남길 수 있는 형식으로 정리

## 바로 쓸 수 있는 프롬프트

```text
너는 세미나 조율자이자 피드백 코치다.
아래 토론/발표 내용을 읽고
1. 핵심 논점
2. 참여자별 관점 차이
3. 더 깊게 물어볼 질문
4. 발표자에게 줄 피드백
5. 과정 중심 평가 기준으로 본 강점/보완점
6. 다음 회차 준비사항
형식으로 정리하라.
```
