# 학생용 30일 AI Native 전환 플랜

## 1주차: 익숙해지기

- 매일 하나의 반복 업무를 AI에 설명해본다.
- 같은 작업을 2개 이상의 도구로 시도해본다.
- 잘 나온 프롬프트를 저장한다.

## 2주차: 구조화하기

- 자주 하는 작업 3개를 고른다.
- 각 작업을 `입력 / 처리 / 출력 / 검증`으로 나눈다.
- 가장 단순한 템플릿을 만든다.

## 3주차: 자동화하기

- 회의록 정리, 자료 요약, 공지문 작성 중 하나를 반자동화한다.
- 텍스트 파일, 스프레드시트, 노션 중 하나와 연결해본다.

## 4주차: 자산화하기

- 프롬프트를 문서로 정리한다.
- 개인용 skill 문서를 만든다.
- 작은 Agent 예제를 하나 직접 수정해본다.
- 깃허브 레포에 축적한다.

## 30일 후 목표

1. 내가 반복하는 일 3개를 AI workflow로 설명할 수 있다.
2. 좋은 프롬프트/체크리스트 5개 이상을 보유한다.
3. 함수 호출형 Agent 예제를 직접 한 번 돌려봤다.
4. AI를 소비하는 수준에서 벗어나 축적하는 수준으로 이동한다.
