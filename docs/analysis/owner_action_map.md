# 회의 액션아이템 담당자 맵과 AI 지원 포인트

## 목적

회의록의 액션아이템을 담당 기준으로 정리하고, 각 담당자가 AI에게 어떤 종류의 도움을 기대하면 좋은지 연결한다.

## 액션아이템 원문 요약

1. Ethan Mollick 자료 공유
2. AI 조율자 프롬프트 설계
3. 캡스톤 구조 설계
4. 데이터베이스 구축
5. 멘토 풀 구성
6. Vibe Coding 세션
7. 프롬프팅 가이드 정리

## 담당 기준 정리

### C (나 교수)

담당:

- Ethan Mollick 자료 공유
- 캡스톤 구조 설계 공동
- 멘토 풀 구성

AI에게 기대할 수 있는 역할:

- `리서치 큐레이터`
  - Ethan Mollick 자료, MIT Thinking Lab, Watson School 관련 레퍼런스 요약
- `커리큘럼 설계 보조`
  - 5~6주 캡스톤 구조 초안 생성
- `멘토 운영 코디네이터`
  - 멘토 역할 정의, 매칭 기준, 멘토 브리프 초안 생성

좋은 요청 예시:

```text
아름다운서당의 교육 철학은 사고력과 리더십 강화다.
이 전제를 유지하면서 5~6주 캡스톤 프로젝트 구조 초안을 설계해줘.
각 주차별 목표, 학생 산출물, 멘토 개입 포인트를 포함해줘.
```

### B (주빈)

담당:

- AI 조율자 프롬프트 설계
- Vibe Coding 세션 공동

AI에게 기대할 수 있는 역할:

- `Prompt Architect`
  - AI Facilitator 프롬프트 설계
- `세션 시뮬레이터`
  - 실제 토론 상황에서 어떤 질문과 개입이 필요한지 시뮬레이션
- `워크숍 디자이너`
  - 비개발자 대상 Vibe Coding 세션 흐름 설계

좋은 요청 예시:

```text
너는 팀 토론을 돕는 AI Facilitator 프롬프트 설계자다.
학생 팀이 문제 정의, 갈등 조율, 합의 도출을 할 수 있도록
개입 질문, 중간 요약, 합의 체크 문구를 포함한 시스템 프롬프트를 작성해줘.
```

### D (상민)

담당:

- 데이터베이스 구축
- Vibe Coding 세션 공동
- 프롬프팅 가이드 정리

AI에게 기대할 수 있는 역할:

- `정보 구조 설계 보조`
  - 자료를 어떤 스키마로 쌓을지 제안
- `문서화 보조`
  - 학생용 프롬프팅 가이드 초안 작성
- `시스템 기획 파트너`
  - DB 최소 요구사항, 운영 룰, 권한 범위 정리

좋은 요청 예시:

```text
기수별로 분산된 발표자료, 토론 로그, 프로젝트 산출물을 교수진 전용 DB로 통합하려고 한다.
최소 스키마, 메타데이터 항목, 검색 단위, 접근 권한 구조를 제안해줘.
```

### F (이사장)

담당:

- 캡스톤 구조 설계 공동

AI에게 기대할 수 있는 역할:

- `평가 관점 정리자`
  - 과정 중심 평가 기준 초안 생성
- `리더십 교육 번역자`
  - 사고력/리더십 철학을 프로젝트 운영 기준으로 변환

좋은 요청 예시:

```text
결과 중심 평가가 아니라 과정 중심 평가를 하려 한다.
문제 정의, 자료 조사, 팀 토론, 해결 도출, 발표를 기준으로 평가 루브릭 초안을 설계해줘.
```

## 학생 관점으로 재해석하면

이 담당 구조는 학생들에게도 그대로 적용된다.

- 발표 담당은 AI를 `논리 코치`로 쓴다.
- 사회 담당은 AI를 `조율자 보조`로 쓴다.
- 기록 담당은 AI를 `회의록 정리자`로 쓴다.
- 프로젝트 리더는 AI를 `구조 설계 파트너`로 쓴다.
