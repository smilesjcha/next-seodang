# AI 시대 직무 지도: 역할, 협업, 그리고 Multiplier로의 진화

## 전체 운영 기준

- 강의 90분 기준
- 60장 기준 평균 90초 미만이 아니라, 실제로는 `전환 장표 20~40초`, `핵심 장표 60~120초`로 운영
- 권장 구성:
  - 강의 75~90분
  - Q&A 10~30분
- 목표:
  - 3명의 실제 요청 사례를 통해 AI/Agent 활용을 이해시킨다
  - Agent의 기초를 직관적으로 이해시킨다
  - Colab 실습으로 작은 Agent를 직접 보게 한다
  - AI Native 운영법과 Skill Setting까지 연결한다

## 전체 파트 구성

1. Opening & 관점 세팅
