# 강의용 실전 AI 스택 정리

## 학생들에게 추천할 기본 스택

### 1. 사고와 문서 작업

- ChatGPT
- Claude
- Gemini

용도:

- 글 초안
- 요약
- 구조화
- 질문 생성
- 발표 흐름 잡기

## 2. 탐색과 리서치

- Perplexity
- ChatGPT Search 또는 Gemini 검색 연동

용도:

- 빠른 탐색
- 출처 확인
- 관점 비교

## 3. 코드와 자동화

- Google Colab
- GitHub
- Claude Code / Codex

용도:

- 작은 자동화 실험
- 함수 호출형 Agent 실습
- 프롬프트/코드 자산 축적

## 4. 문서 및 운영

- Notion
- Google Docs / Sheets

용도:

- 회의록
- 스터디 운영
- 결과물 정리

## 발표에서 공유하면 좋은 개인 세팅 예시

### 세팅 A. 범용 지식노동자형

- ChatGPT: 사고 정리
- Claude: 긴 문서 작성/요약
- Notion: 기록
- GitHub: 자산 저장

### 세팅 B. 학생/스터디 운영형

- Gemini 또는 ChatGPT: 공지/요약/질문 생성
- Perplexity: 자료 탐색
- Google Docs: 공동 편집
- Colab: 간단한 코드 실습

### 세팅 C. Builder형

- ChatGPT / Claude: 설계 및 코드 초안
- Codex / Claude Code: 구현
- GitHub: 버전 관리
- Colab 또는 로컬 Python: 데모/실험

## 중요한 메시지

- 툴을 많이 쓰는 것이 목적이 아니다.
- 자신의 문제 흐름에 맞게 2~4개 정도의 스택을 고정하는 것이 더 중요하다.
- 강한 사람은 툴을 바꾸는 사람이 아니라, 축적 가능한 운영 방식을 가진 사람이다.
