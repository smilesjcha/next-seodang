# 넥스트서당 강의 전략

## 강의의 한 줄 목표

청중이 "AI를 신기한 기술"이 아니라 "내 문제를 푸는 operating system"으로 인식하게 만드는 것.

## 이 강의의 메인 메시지

1. AI Native는 단순히 ChatGPT를 쓰는 사람이 아니다.
2. AI Native는 `문제를 구조화하고`, `Agent와 Tool을 붙이고`, `반복 가능한 방식으로 축적하는 사람`이다.
3. 좋은 사용자는 질문을 잘하는 사람이 아니라, `업무를 시스템으로 분해`할 수 있는 사람이다.
4. 결국 생산성을 올리는 사람은 "혼자 잘하는 사람"이 아니라 "AI를 통해 자신을 multiplier로 만드는 사람"이다.

## 청중 맞춤 포지셔닝

이번 청중은 개발자만이 아니다. 따라서 강의는 "모델 구조" 중심보다 아래 순서를 따라야 한다.

1. 내 일은 왜 반복되는가
2. 어떤 부분을 AI에 맡길 수 있는가
3. Agent는 무엇이 다른가
4. 실제로 어디까지 쓸 수 있는가
5. 오늘 이후 무엇부터 시작할 것인가

## 추천 전체 흐름

### Part 1. 시대 변화

- AI Native 시대에 직무가 어떻게 바뀌는가
- 왜 "역할"보다 "문제 해결 방식"이 중요해지는가
- Multiplier 개념 소개

### Part 2. 현실 활용

- 학생, 연구, 사업, 구매 각각의 현실 문제 예시
- 설문 3명의 실제 니즈 분석
- 생성형 AI가 잘하는 일과 못하는 일

### Part 3. Agent 입문

- Prompt와 Agent의 차이
- Agent = 목표 + 판단 + 도구 사용 + 메모리 + 반복
- Functions, MCP, A2A 개념을 직관적으로 설명

### Part 4. 실습

- Colab에서 간단한 함수 호출형 Agent 시연
- Tool 2~3개를 붙인 작은 루프
- "사람이 직접 하던 중간 단계가 줄어드는 경험" 제공

### Part 5. AI Native 운영법

- 개인 OS 만들기
- 프롬프트, 체크리스트, 스킬, 리포지토리 축적
- 앞으로 어떤 사람으로 진화할 것인가

## 강의에서 반드시 잡아야 할 균형

### 너무 기술적으로 가지 말 것

- 학생 다수가 따라오지 못하면 Agent 파트가 오히려 추상적으로 느껴진다.
- 코드 데모는 "원리 이해용"으로 짧게 가고, 중요한 것은 사고방식이다.

### 너무 추상적으로만 가지 말 것

- "AI Native가 중요하다"는 선언만 있으면 공허하다.
- 반드시 실제 워크플로우 예시, 화면 예시, 코드 예시가 필요하다.

## 추천 시간 배분

- 10분: 왜 지금 AI Native인가
- 15분: 직무와 Multiplier 구조
- 10분: 설문 3명 사례
- 15분: Agent 개념 설명
- 10분: Colab 코드 데모
- 10분: 툴 스택/개인 세팅 공유
- 10분: 학생들이 바로 시작할 30일 플랜

총 70분 전후를 기준으로 설계하고, 짧게 줄일 경우 사례와 데모만 남기면 된다.

## 본 강의에서 현실적으로 보여주기 좋은 것

### 강하게 추천

- 단일 Agent + 함수 2~3개
- 문서 요약 + TODO 정리 + 질문 생성
- 간단한 CSV 정리/요약
- PDF/텍스트 기반 근거 찾기 개념 소개

### 선택적으로 소개

- MCP는 "외부 도구 연결 표준" 정도까지 설명
- A2A는 "Agent끼리 역할을 나눠 협업"하는 개념과 예시 정도까지 설명

### 과하게 깊게 들어가지 말 것

- 복잡한 multi-agent orchestration
- 장기 메모리 구조의 구현 디테일
- 벤더별 세부 SDK 차이

## 오늘 강의에서 전하고 싶은 결론

강의의 마지막 메시지는 다음 문장으로 모을 수 있다.

> AI Native는 AI를 많이 쓰는 사람이 아니라,
> 자기 일의 구조를 이해하고 AI를 붙여 반복 가능한 시스템으로 만드는 사람이다.
