# 3. 토요일 수업 시간 운영 방식

교육은 **6개월, 총 25주**, 매주 토요일 **10:00~17:30**에 진행됩니다.

| 시간대  | 활동                | 목적               |
| ---- | ----------------- | ---------------- |
| 수업 전 | 독서, 보고서 작성, 카페 공유 | 개인 사고 정리         |
| 오전   | 개인별 3분 발표         | 핵심 메시지 전달 훈련     |
| 중간   | 조별 심층 토론          | 경청, 조정, 합의 훈련    |
| 오후   | 조별 결과 발표          | 팀 논리 구조화 및 발표    |
| 후반   | 전체 토의             | 다양한 관점 비교        |
| 마무리  | 교수 종합 피드백         | 핵심 개념 정리 및 사고 확장 |
| 수업 후 | 개인 자료 수정          | 학습 내용 체화         |

조별 토론에서는 역할을 나누어 운영합니다.

| 역할    | 주요 책임            |
| ----- | ---------------- |
| 조장    | 토론 진행, 쟁점 제시     |
| 서기    | 토론 내용 요약 및 정리    |
| 발표자   | 조별 결론 발표         |
| 시간관리자 | 발언 시간 및 전체 흐름 관리 |
