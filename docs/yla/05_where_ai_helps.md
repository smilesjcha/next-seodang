# 5. AI가 도우면 좋은 부분

AI는 학생의 사고를 대신하는 도구가 아니라, **읽기·쓰기·발표·토론 준비의 보조 코치**로 활용하는 것이 적절합니다.

| 학습 단계    | AI 활용 포인트                | 기대 효과     |
| -------- | ------------------------ | --------- |
| 독서 전     | 고전의 시대 배경, 저자, 핵심 개념 요약  | 진입 장벽 완화  |
| 독서 중     | 핵심 쟁점 3~5개 정리, 어려운 문장 해설 | 이해 속도 향상  |
| 보고서 작성   | 논리 구조 점검, 주장-근거 연결 확인    | 글의 완성도 향상 |
| 발표 준비    | 3분 발표 스크립트 압축, 핵심 메시지 정리 | 전달력 강화    |
| 토론 준비    | 예상 질문, 반론, 찬반 논점 생성      | 토론 품질 향상  |
| 조별 활동    | 토론 내용 요약, 합의점·쟁점 분리      | 팀 협업 효율화  |
| 수업 후     | 교수 피드백 기반 보고서 개선         | 학습 내용 체화  |
| 프로젝트 세미나 | 사회 이슈 리서치, 데이터·사례 조사     | 현실 적용력 강화 |
