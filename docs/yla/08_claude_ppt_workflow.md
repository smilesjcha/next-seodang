# 8. Claude 기반 PPT 초안 제작 및 자가 수정 / 피드백 기반 수정 흐름

**AI 활용 흐름에 "Claude로 PPT 초안 생성" 단계를 넣는 것이 매우 적절**합니다. 다만 목적은 "대신 만들어주기"가 아니라, **학생의 사고를 구조화하고 발표 품질을 빠르게 높이는 도구**로 잡는 게 좋습니다.

## 추가하면 좋은 학습 흐름

| 단계 | 기존 활동     | AI/Claude 활용          |
| -- | --------- | --------------------- |
| 1  | 고전 독서     | 핵심 개념·시대 배경 이해 보조     |
| 2  | 개인 보고서 작성 | 논리 구조·주장-근거 점검        |
| 3  | 조별 토론     | 쟁점, 반론, 합의점 정리        |
| 4  | 발표 준비     | **Claude로 PPT 초안 생성** |
| 5  | 발표 리허설    | 발표 스크립트, 예상 질문, 시간 조정 |
| 6  | 수업 후 수정   | 피드백 반영해 최종 자료 개선      |

## Claude PPT 생성 과정 예시

| 입력 자료    | Claude가 도울 수 있는 산출물   |
| -------- | --------------------- |
| 개인 보고서   | 3분 발표용 3~5장 슬라이드      |
| 조별 토론 정리 | 5분 팀 발표용 PPT          |
| 교수 핵심 질문 | 발표 흐름 재구성             |
| 고전 핵심 쟁점 | 문제 제기 → 분석 → 시사점 구조   |
| 발표 시간    | 장표 수, 발표 스크립트, 예상 Q&A |

## 권장 프로세스

1. **학생이 먼저 보고서/에세이 작성**
2. **조별 토론 후 핵심 메시지 정리**
3. Claude에 입력

   * 주제
   * 핵심 주장
   * 근거 3개
   * 반론/한계
   * 현대 사회 적용점
   * 발표 시간
4. Claude가 PPT 초안 생성
5. 학생이 직접 수정

   * 논리 오류 검토
   * 자기 관점 추가
   * 불필요한 내용 삭제
   * 발표 메시지 압축
6. 최종 발표 및 피드백 반영

## Claude 프롬프트 예시

```text
아래 내용을 바탕으로 아름다운서당 YLA 세미나 발표용 PPT 초안을 만들어줘.

주제:
[고전명 / 사회 이슈]

발표 목적:
3분 개인 발표 또는 5분 조별 발표

핵심 주장:
[내가 전달하고 싶은 한 문장]

주요 근거:
1. 
2. 
3. 

토론에서 나온 쟁점:
- 찬성 관점:
- 반대 관점:
- 합의 가능한 지점:

현대 사회 적용:
[AI 시대, 리더십, 조직, 사회 문제 등과 연결]

요청 형식:
- 슬라이드 5장 이내
- 각 슬라이드는 제목 1개, 핵심 bullet 3개 이내
- 마지막 장에는 시사점 포함
- 발표자 스크립트도 슬라이드별로 작성
- 학생이 직접 말하는 자연스러운 톤으로 작성
```

## 최종 정리

AI 활용 단계에 **"보고서 → 토론 정리 → Claude PPT 초안 → 학생 수정 → 발표 리허설"**을 넣으면 좋습니다.

핵심은 다음입니다.

> AI는 학생의 생각을 대신 만드는 도구가 아니라, 학생이 읽고 토론한 내용을 발표 가능한 구조로 바꿔주는 학습 보조 도구로 활용한다.
