# 2. 학생들이 공부하는 과정

아름다운서당의 학습 구조는 **읽기 → 쓰기 → 말하기 → 토론하기 → 수정하기**의 반복 훈련입니다.

| 단계               | 학생 활동                       | 산출물                        |
| ---------------- | --------------------------- | -------------------------- |
| **1. 사전 준비**     | 2주 전 도서 수령, 교수의 세미나 계획서 확인  | 독서 계획                      |
| **2. 핵심 독서**     | 교수가 제시한 핵심 포인트 3~5개 중심으로 독서 | 핵심 쟁점 메모                   |
| **3. 개인 정리**     | 자신의 논리로 쟁점 정리               | 2쪽 이내 개조식 보고서 또는 2000자 에세이 |
| **4. 사전 공유**     | 작성한 보고서·에세이를 카페에 업로드        | 공유 자료                      |
| **5. 개인 발표**     | 모든 학생이 3분 발표                | 개인 발표                      |
| **6. 조별 토론**     | 핵심 쟁점 중심으로 심층 토론            | 조별 결론                      |
| **7. 팀 발표**      | 조별 토론 결과를 5분 내 발표           | 팀 발표                       |
| **8. 전체 토의**     | 다른 조 의견 비교, 질문, 반론          | 관점 확장                      |
| **9. 교수 피드백**    | 교수의 종합 정리 및 피드백             | 개선 방향                      |
| **10. 개인 자료 수정** | 피드백을 반영해 보고서 보완             | 작품집·캠프용 최종 자료              |
