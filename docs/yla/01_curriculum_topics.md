# 1. 아름다운서당 YLA 학생들이 공부하는 주제

아름다운서당 YLA는 **AI 시대의 리더십 역량**을 기르기 위해 크게 두 축으로 공부합니다.

| 구분               | 학습 주제                                          | 목적                                  |
| ---------------- | ---------------------------------------------- | ----------------------------------- |
| **동서양 인문고전 세미나** | 서양 철학·문학, 동양 철학, 한국 역사 고전 20권                  | 인간·사회·국가·시장·정의·리더십에 대한 통찰 형성        |
| **프로젝트 세미나**     | AI 활용법, 미래 리더십, 저출생·고령화, 산업 AX, 지역균형발전 등 사회 이슈 | 고전의 지혜를 현실 문제에 적용하고 팀 기반 문제해결 역량 강화 |

## 고전 학습의 핵심 질문

학생들은 단순히 책 내용을 요약하는 것이 아니라, 다음 질문을 중심으로 사고합니다.

| 핵심 질문                 | 예시                               |
| --------------------- | -------------------------------- |
| 이 고전이 왜 중요한가?         | 왜 『국가론』, 『논어』, 『국부론』을 지금 읽어야 하는가 |
| 저자의 핵심 주장은 무엇인가?      | 자유, 정의, 권력, 인간 본성, 시장경제에 대한 관점   |
| 그 주장은 오늘날 어떤 의미가 있는가? | AI 시대 리더십, 민주주의, 기업 경영, 사회문제 해결  |
| 나는 어떻게 해석하고 적용할 것인가?  | 개인의 판단 기준, 조직·사회 문제 해결 방식        |
