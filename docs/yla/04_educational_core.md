# 4. 이 과정의 교육적 핵심

아름다운서당의 학습은 지식 습득보다 **리더십 훈련**에 가깝습니다.

| 역량    | 훈련 방식                |
| ----- | -------------------- |
| 통찰력   | 고전에서 인간과 사회의 본질 파악   |
| 판단력   | 핵심 쟁점에 대한 자기 입장 정립   |
| 표현력   | 보고서, 에세이, 3분 발표 반복   |
| 소통력   | 조별 토론과 전체 토의         |
| 조정 능력 | 서로 다른 의견을 듣고 합의점 도출  |
| 책임감   | 매주 준비, 발표, 수정의 반복    |
| 문제해결력 | 고전의 지혜를 현실 사회 이슈에 적용 |
